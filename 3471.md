# 🚀 Largest Almost Missing Integer

### 📝 Problem Description

You are given an integer array `nums` and an integer `k`.

An integer `x` is **almost missing** from `nums` if `x` appears in **exactly one** subarray of size `k` within `nums`.

Return the *largest almost missing integer* from `nums`. If no such integer exists, return `-1`.

A **subarray** is a contiguous sequence of elements within an array.

---

### 💡 Intuition & Strategy

1. **Subarray Window Analysis**:
   * Total number of contiguous subarrays of size `k` in an array of size `n` is $n - k + 1$.
   * We need to count how many distinct size-$k$ windows contain each unique integer $x$.

2. **Case Breakdown ($O(N)$ Optimization)**:
   * **Case 1: $k = 1$**:
     * Each element forms its own subarray of size $1$.
     * A number appears in exactly one subarray if and only if its **global frequency** in `nums` is `1`.
     * **Result**: Return the maximum element with `frequency == 1`.
   * **Case 2: $k = n$**:
     * There is only one subarray of size $n$ (the entire array itself).
     * Every distinct integer present in `nums` appears in exactly this single subarray.
     * **Result**: Return the global maximum element in `nums`.
   * **Case 3: $1 < k < n$**:
     * Any interior element (`nums[i]` where $0 < i < n - 1$) is guaranteed to be covered by at least two overlapping windows of size $k$.
     * Therefore, only the boundary elements (`nums[0]` and `nums[n - 1]`) can possibly appear in exactly one window of size $k$.
     * A boundary element is valid only if its total occurrence in the entire array is `1` (it does not repeat elsewhere).
     * **Result**: Return $\max(\text{valid } nums[0], \text{valid } nums[n - 1])$, or `-1` if neither is valid.

3. **Complexity**:
   * **Time Complexity**: **$O(N)$** — A single pass to compute frequencies, followed by $O(1)$ constant-time checks.
   * **Space Complexity**: **$O(1)$** — Uses a fixed-size frequency array (values are bounded by constraint $0 \le \text{nums}[i] \le 50$).

---

### 💻 Java Solution

```java
/**
 * Problem: LeetCode - Largest Almost Missing Integer
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 */
public class Solution {

    public int largestInteger(int[] nums, int k) {
        int n = nums.length;
        int[] freq = new int[51];

        // Step 1: Count total occurrences of each number
        for (int num : nums) {
            freq[num]++;
        }

        // Case 1: k == 1 -> find the largest number with global frequency of 1
        if (k == 1) {
            int maxVal = -1;
            for (int i = 0; i <= 50; i++) {
                if (freq[i] == 1) {
                    maxVal = Math.max(maxVal, i);
                }
            }
            return maxVal;
        }

        // Case 2: k == n -> the entire array is the only subarray, return global max
        if (k == n) {
            int maxVal = -1;
            for (int num : nums) {
                maxVal = Math.max(maxVal, num);
            }
            return maxVal;
        }

        // Case 3: 1 < k < n -> only unique boundary elements can appear in exactly 1 window
        int maxVal = -1;
        if (freq[nums[0]] == 1) {
            maxVal = Math.max(maxVal, nums[0]);
        }
        if (freq[nums[n - 1]] == 1) {
            maxVal = Math.max(maxVal, nums[n - 1]);
        }

        return maxVal;
    }
}
```
