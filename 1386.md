# 🚀 Cinema Seat Allocation

### 📝 Problem Description

A cinema has $n$ rows of seats, numbered from $1$ to $n$. Each row has $10$ seats, numbered from $1$ to $10$.

You are given a 2D integer array `reservedSeats`, where `reservedSeats[i] = [rowi, seati]` means that seat `seati` in row `rowi` is already reserved.

A four-person group must be assigned to four contiguous seats in the same row. The group can be seated in one of the following seat blocks:
- **Left block**: seats `2, 3, 4, 5`
- **Right block**: seats `6, 7, 8, 9`
- **Middle block**: seats `4, 5, 6, 7`

A block can be used only if none of its seats are reserved. Each seat can be assigned to at most one group.

Return the maximum number of four-person groups that can be assigned.

---

### 💡 Intuition & Strategy

1. **Ignore Irrelevant Seats**:
   - Seats `1` and `10` are at the extreme ends of the row and never participate in any valid 4-person block (`[2, 3, 4, 5]`, `[4, 5, 6, 7]`, `[6, 7, 8, 9]`).
   - Reservations on seats `1` and `10` can be completely ignored.

2. **Default Capacity for Unreserved Rows**:
   - A completely empty row can host at most **$2$ groups**: one in the left block (`[2, 3, 4, 5]`) and one in the right block (`[6, 7, 8, 9]`).
   - If there are rows without any reservations (or only reservations on seats $1$ and $10$), each such row automatically contributes $2$ to the final answer.

3. **Bitmask Representation**:
   - Represent reserved seats in each row using a lightweight integer bitmask.
   - For each row with relevant reserved seats (seats $2$ through $9$), map `row -> bitmask`, where the $c$-th bit is set if seat $c$ is reserved:
     $$\text{mask} = \text{mask} \mid (1 \ll c)$$

4. **Greedy Group Placement per Affected Row**:
   - **Left Block Mask**: `(1 << 2) | (1 << 3) | (1 << 4) | (1 << 5)` (seats $2, 3, 4, 5$)
   - **Right Block Mask**: `(1 << 6) | (1 << 7) | (1 << 8) | (1 << 9)` (seats $6, 7, 8, 9$)
   - **Middle Block Mask**: `(1 << 4) | (1 << 5) | (1 << 6) | (1 << 7)` (seats $4, 5, 6, 7$)

   For each row with reservations:
   - **Both Left & Right Available**: If `(mask & leftMask) == 0` and `(mask & rightMask) == 0`, we can fit **$2$ groups**.
   - **At Least One Block Available**: If the left block, right block, or middle block is free, we can fit **$1$ group**.
   - **Otherwise**: $0$ groups can be placed.

5. **Complexity**:
   - **Time Complexity**: **$O(M)$** — where $M$ is the length of `reservedSeats`. Iterating through reserved seats takes $O(M)$ time, and evaluating affected rows in the hash map takes at most $O(M)$ time.
   - **Space Complexity**: **$O(M)$** — to store bitmasks for at most $M$ unique rows in the hash map.

---

### 💻 Java Solution

```java
import java.util.HashMap;
import java.util.Map;

/**
 * Language: Java 17
 * Time Complexity: O(M) where M = reservedSeats.length
 * Space Complexity: O(M)
 */
public class Solution {

    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        // Step 1: Map row numbers to bitmasks representing occupied seats (2-9)
        Map<Integer, Integer> rowMasks = new HashMap<>();

        for (int[] seat : reservedSeats) {
            int row = seat[0];
            int col = seat[1];
            
            // Only seats 2 through 9 can affect 4-person block placements
            if (col >= 2 && col <= 9) {
                rowMasks.put(row, rowMasks.getOrDefault(row, 0) | (1 << col));
            }
        }

        // Step 2: Every row with no relevant reservations accommodates 2 groups
        int maxGroups = (n - rowMasks.size()) * 2;

        // Bitmasks corresponding to the three valid 4-person configurations
        int leftMask = (1 << 2) | (1 << 3) | (1 << 4) | (1 << 5);   // Seats 2, 3, 4, 5
        int rightMask = (1 << 6) | (1 << 7) | (1 << 8) | (1 << 9);  // Seats 6, 7, 8, 9
        int middleMask = (1 << 4) | (1 << 5) | (1 << 6) | (1 << 7); // Seats 4, 5, 6, 7

        // Step 3: Evaluate rows with reservations
        for (int mask : rowMasks.values()) {
            boolean leftFree = (mask & leftMask) == 0;
            boolean rightFree = (mask & rightMask) == 0;
            boolean middleFree = (mask & middleMask) == 0;

            if (leftFree && rightFree) {
                // Both independent blocks are completely open
                maxGroups += 2;
            } else if (leftFree || rightFree || middleFree) {
                // At least one valid 4-seat block can be seated
                maxGroups += 1;
            }
        }

        return maxGroups;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Notes |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(M)$ | We iterate through the $M$ reserved seats once to populate the hash map, and then process at most $M$ unique row entries ($M \le 10^4$). |
| **Space Complexity** | $\mathcal{O}(M)$ | Requires a hash map to store the bitmasks of only the affected rows with reservations, consuming at most $M$ key-value pairs. |
