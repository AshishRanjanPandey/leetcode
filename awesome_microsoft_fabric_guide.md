## 🏗️ Core Components of Microsoft Fabric

When working with Microsoft Fabric, you will interact with several integrated workloads:

1. **OneLake:** The unified "OneDrive for Data" providing a single, open delta lake storage format across your entire organization.

2. **Data Factory:** Hybrid data integration to build ETL/ELT pipelines using fast data flows and data pipelines.

3. **Synapse Data Engineering:** Apache Spark-based processing for large-scale data transformation and data science.

4. **Synapse Real-Time Analytics:** Ultra-fast query engine tailored for high-volume telemetry, logs, and streaming data.

5. **Power BI:** Industry-standard visualization and reporting powered by DirectLake mode for real-time querying.
