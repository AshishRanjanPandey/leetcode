# 🚀 Longest Subsequence With Non-Zero Bitwise XOR

### 📝 Problem Description

You are given an integer array `nums`.

Return the length of the longest subsequence in `nums` whose bitwise XOR is non-zero. If no such subsequence exists, return `0`.

---

### 💡 Intuition & Strategy

1. **Subsequence Properties**:
   * A subsequence is formed by deleting zero or more elements from the array without changing the order of the remaining elements.
   * To maximize the length of a subsequence, our best candidate is the entire array `nums` of length $N$.

2. **Bitwise XOR Observations**:
   * Let $T = \text{nums}[0] \oplus \text{nums}[1] \oplus \dots \oplus \text{nums}[N - 1]$ be the total XOR sum of all elements.
   * **Case 1: All elements are `0`**:
     * Any subset/subsequence will only ever have a bitwise XOR of $0$.
     * Hence, no valid non-zero XOR subsequence exists. Return **`0`**.
   * **Case 2: Total XOR sum is non-zero ($T \neq 0$)**:
     * The entire array itself is a valid subsequence of length $N$ with a non-zero XOR.
     * Since length $N$ is the theoretical maximum possible, return **$N$**.
   * **Case 3: Total XOR sum is zero ($T = 0$) but contains non-zero elements**:
     * The entire array has an XOR sum of $0$, so we cannot take all $N$ elements.
     * If we remove any single non-zero element $x$ from `nums`, the XOR sum of the remaining $N - 1$ elements becomes:
       $$\text{XOR}_{\text{remaining}} = T \oplus x = 0 \oplus x = x$$
     * Since $x \neq 0$, the XOR sum of this $(N - 1)$-length subsequence is guaranteed to be non-zero.
     * Hence, the maximum possible length is **$N - 1$**.

3. **Time and Space Complexity**:
   * A single linear pass through `nums` computes both the total XOR sum and checks for the presence of any non-zero elements.
   * Time Complexity: **$O(N)$**
   * Space Complexity: **$O(1)$**

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 */
public class Solution {

    public int longestSubsequence(int[] nums) {
        int totalXor = 0;
        boolean hasNonZero = false;

        for (int num : nums) {
            totalXor ^= num;
            if (num != 0) {
                hasNonZero = true;
            }
        }

        // Case 1: If every element in nums is 0, no non-zero XOR subsequence exists
        if (!hasNonZero) {
            return 0;
        }

        // Case 2: If the XOR sum of the entire array is non-zero, we can take all elements
        if (totalXor != 0) {
            return nums.length;
        }

        // Case 3: If total XOR is 0, remove one non-zero element to get XOR = (0 ^ x) = x != 0
        return nums.length - 1;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |

| **Time Complexity** | $\mathcal{O}(N)$ | Single linear pass through the array to compute the XOR sum and check for non-zero elements. |
| **Space Complexity** | $\mathcal{O}(1)$ | Uses a constant amount of extra memory for two primitive variables (`totalXor`, `hasNonZero`). |
