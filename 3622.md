# 🔢 Check If Number Is Divisible By Sum and Product of Digits

### 📝 Problem Description

You are given a positive integer `n`. Determine whether `n` is divisible by the sum of the following two values:
1. The **digit sum** of `n` (the sum of its digits).
2. The **digit product** of `n` (the product of its digits).

Return `true` if `n` is divisible by this sum; otherwise, return `false`.

---

### 💡 Intuition & Strategy

1. **Digit Extraction**:
   * Repeatedly extract the least significant digit using the modulo operator `temp % 10`.
   * Update the running sum (`digSum += digit`) and running product (`digProduct *= digit`).
   * Reduce the number using integer division `temp /= 10` until `temp == 0`.

2. **Divisor Construction & Division Check**:
   * Compute the total denominator: `totalDivisor = digSum + digProduct`.
   * For any positive integer $n \ge 1$, `totalDivisor` is guaranteed to be $\ge 1$, eliminating any risk of division by zero.
   * Return the evaluation of `n % totalDivisor == 0`.

3. **Complexity**:
   * **Time Complexity**: $O(\log_{10} n)$ — visits each digit once (at most $7$ iterations for $n \le 10^6$).
   * **Space Complexity**: $O(1)$ — constant space with a few primitive variables.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(log10(n))
 * Space Complexity: O(1)
 */
class Solution {

    public boolean checkDivisibility(int n) {
        int digSum = 0;
        int digProduct = 1;
        int temp = n;

        while (temp > 0) {
            int digit = temp % 10;
            digSum += digit;
            digProduct *= digit;
            temp /= 10;
        }

        int totalDivisor = digSum + digProduct;
        return n % totalDivisor == 0;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :--- | :--- |
| **Time Complexity** | $O(\log_{10} n)$ | Traverses each digit of $n$ once; at most $\lfloor\log_{10} n\rfloor + 1$ iterations ($\le 7$ steps for $n \le 10^6$). |
| **Space Complexity** | $O(1)$ | Uses a fixed number of primitive 32-bit integer variables without auxiliary data structures. |
