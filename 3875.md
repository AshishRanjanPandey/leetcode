# 🎯 LeetCode: Check if Array Can Be Made Uniform (Parity Match)

### 📝 Problem Description

You are given an array `nums1` of $n$ distinct integers.

You want to construct another array `nums2` of length $n$ such that the elements in `nums2` are either all odd or all even.

For each index $i$, you must choose exactly one of the following:
- `nums2[i] = nums1[i]`
- `nums2[i] = nums1[i] - nums1[j]`, for an index $j \neq i$

Return `true` if it is possible to construct such an array, otherwise, return `false`.

---

### 💡 Intuition & Strategy

1. **Parity Subtraction Rules**:
   Recall the basic arithmetic rules for parity under subtraction:
   - $\text{even} - \text{even} = \text{even}$
   - $\text{odd} - \text{odd} = \text{even}$
   - $\text{even} - \text{odd} = \text{odd}$
   - $\text{odd} - \text{even} = \text{odd}$

2. **Targeting an All-Even Array**:
   - If every element in `nums1` is already even, simply take `nums2[i] = nums1[i]` for all $i$. All elements are even.

3. **Targeting an All-Odd Array**:
   - If there is at least one odd element in `nums1`, let one of those odd elements be at index $k$ (i.e., `nums1[k]` is odd).
   - For every element $i$:
     - If `nums1[i]` is odd, keep it: `nums2[i] = nums1[i]` (odd).
     - If `nums1[i]` is even, subtract the odd element: `nums2[i] = nums1[i] - nums1[k]`.
       Since $\text{even} - \text{odd} = \text{odd}$, `nums2[i]` becomes odd.
     - Because `nums1[i]` is even and `nums1[k]` is odd, their values differ, guaranteeing $i \neq k$.

4. **Conclusion**:
   - Any array `nums1` must either consist entirely of even integers, or contain at least one odd integer.
   - If all elements are even, an **all-even** array can always be formed.
   - If there is at least one odd element, an **all-odd** array can always be formed.
   - Therefore, a valid `nums2` array can **always** be formed for any input array under the given constraints.

5. **Complexity**:
   - **Time Complexity**: $O(1)$ — constant time check.
   - **Space Complexity**: $O(1)$ — no extra memory allocated.
