# 🚀 LeetCode 3499 — Maximize Active Section with Trade I

### 📝 Problem Description
You are given a binary string `s` of length `n`, where:
* `'1'` represents an active section.
* `'0'` represents an inactive section.

You can perform **at most one trade** to maximize the number of active sections in `s`. In a trade, you:
1. Convert a contiguous block of `'1'`s that is surrounded by `'0'`s to all `'0'`s.
2. Afterward, convert a contiguous block of `'0'`s that is surrounded by `'1'`s to all `'1'`s.

Return the maximum number of active sections in `s` after making the optimal trade.

> **Note:** Treat `s` as if it is augmented with a `'1'` at both ends, forming $t = \text{"1"} + s + \text{"1"}$. The augmented `'1'`s do not contribute to the final count.

---

### 💡 Intuition & Strategy

1. **Augmentation**:
   Adding `'1'` at both ends turns boundary `'0'` blocks into internal `'0'` blocks surrounded by `'1'`s.
   
2. **Block Decomposition**:
   Decompose $t$ into alternating contiguous blocks of `'1'`s ($A_1, A_2, \dots, A_k$) and `'0'`s ($B_1, B_2, \dots, B_{k-1}$).
   $$t = 1^{a_1} 0^{b_1} 1^{a_2} 0^{b_2} \dots 0^{b_{k-1}} 1^{a_k}$$

3. **Valid Trade Rules**:
   * An internal block $A_i$ ($2 \le i \le k-1$) is strictly surrounded by `'0'`s in $t$.
   * If $k < 3$, no internal block of `'1'`s exists, so no trade can be made.

4. **Trade Evaluation**:
   For each internal block $a_i$, converting it to `'0'`s yields two potential choices for flipping a `'0'` block:
   * **Option A (Merge Adjacent `0`-Blocks)**: Fill the combined block $(b_{i-1} + a_i + b_i)$ with `'1'`s.
     $$\text{Gain}_A = b_{i-1} + b_i$$
   * **Option B (Fill a Non-Adjacent `0`-Block)**: Pick the largest `'0'` block $b_j$ where $j \notin \{i-1, i\}$.
     $$\text{Gain}_B = b_j - a_i$$

5. **Optimization**:
   Precompute prefix and suffix maximum arrays for $B$ to query the largest $b_j$ outside $\{i-1, i\}$ in $O(1)$ time.

---

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.List;

/**
 * Problem: Maximum Active Sections After Trade
 * Language: Java 17
 */
class Solution {
    public int maxActiveSectionsAfterTrade(String s) {
        // Step 1: Construct augmented string t = '1' + s + '1'
        String t = "1" + s + "1";
        int n = t.length();
        
        List<Integer> A = new ArrayList<>(); // 1-block lengths
        List<Integer> B = new ArrayList<>(); // 0-block lengths
        
        int initialOnes = 0;
        for (char c : s.toCharArray()) {
            if (c == '1') initialOnes++;
        }
        
        // Step 2: Extract block lengths
        int idx = 0;
        while (idx < n) {
            int onesCount = 0;
            while (idx < n && t.charAt(idx) == '1') {
                onesCount++;
                idx++;
            }
            A.add(onesCount);
            
            if (idx < n) {
                int zerosCount = 0;
                while (idx < n && t.charAt(idx) == '0') {
                    zerosCount++;
                    idx++;
                }
                B.add(zerosCount);
            }
        }
        
        int k = A.size();
        // If there are no internal '1' blocks surrounded by '0's
        if (k < 3) {
            return initialOnes;
        }
        
        int m = B.size(); // m = k - 1
        
        // Step 3: Precompute prefix and suffix max arrays for B
        int[] prefMax = new int[m];
        int[] suffMax = new int[m];
        
        prefMax[0] = B.get(0);
        for (int i = 1; i < m; i++) {
            prefMax[i] = Math.max(prefMax[i - 1], B.get(i));
        }
        
        suffMax[m - 1] = B.get(m - 1);
        for (int i = m - 2; i >= 0; i--) {
            suffMax[i] = Math.max(suffMax[i + 1], B.get(i));
        }
        
        int maxGain = 0;
        
        // Step 4: Evaluate trade options for each internal 1-block
        for (int i = 1; i < k - 1; i++) {
            int a_i = A.get(i);
            int b_left = B.get(i - 1);
            int b_right = B.get(i);
            
            // Option A: Fill the merged adjacent 0-block
            int gainA = b_left + b_right;
            
            // Option B: Fill a non-adjacent 0-block
            int maxOtherB = Integer.MIN_VALUE;
            if (i - 2 >= 0) {
                maxOtherB = Math.max(maxOtherB, prefMax[i - 2]);
            }
            if (i + 1 < m) {
                maxOtherB = Math.max(maxOtherB, suffMax[i + 1]);
            }
            
            int gainB = (maxOtherB != Integer.MIN_VALUE) ? (maxOtherB - a_i) : 0;
            
            maxGain = Math.max(maxGain, Math.max(gainA, gainB));
        }
        
        return initialOnes + maxGain;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(n)$ | Single pass to parse block lengths, plus linear scans for prefix/suffix max precomputation and block evaluation. |
| **Space Complexity** | $\mathcal{O}(n)$ | Auxiliary storage for the block length lists (`A` and `B`) and prefix/suffix maximum arrays. |
