# 🚀 K-th Lexicographically Smallest Palindromic Permutation

### 📝 Problem Description

Given a palindromic string `s` and an integer `k`, return the **k-th lexicographically smallest palindromic permutation** of `s`. If there are fewer than `k` distinct palindromic permutations, return an **empty string** `""`.

*Note:* Different rearrangements that yield the same palindromic string are considered identical and are counted once.

---

### 💡 Intuition & Strategy

1. **Reduction to Left Half**:
   * A palindrome is symmetric and completely defined by its **left half** and a **middle character** (if the length is odd).
   * Finding the $k$-th lexicographically smallest palindromic string is equivalent to finding the **$k$-th lexicographically smallest permutation** of the available characters in the left half.

2. **Combinatorial Counting & Capping**:
   * For a given multiset of available characters with frequency counts $c_a, c_b, \dots, c_z$, the number of distinct permutations is:
     $$\text{Total Permutations} = \frac{N!}{c_a! \times c_b! \times \dots \times c_z!}$$
   * Since $k \le 10^6$, any permutation count exceeding $10^6 + 1$ can be capped at `LIMIT = 1,000,001` to avoid integer overflow while keeping counting fast.

3. **Digit-by-Digit (Backtracking Choice) Construction**:
   * We build the left half character-by-character from left to right.
   * At each position, we iterate through characters `'a'` to `'z'`:
     * Temporarily pick character `c` and calculate how many distinct left-half permutations can be formed with the remaining unused characters (`ways`).
     * **If `ways >= k`**: The target $k$-th permutation starts with character `c` at this position. Append `c` to our left half and proceed to the next position.
     * **If `ways < k`**: Skip all permutations starting with `c`, subtract `ways` from $k$ ($k = k - \text{ways}$), backtrack character `c`, and try the next available character.

4. **Constructing the Result**:
   * If total possible palindromic permutations are less than $k$, return `""`.
   * Otherwise, assemble: `leftHalf` + `middleChar` (if present) + `reverse(leftHalf)`.

---

### 💻 Java Solution

```java
/**
 * Problem: K-th Lexicographically Smallest Palindromic Permutation
 * Language: Java 17
 * Time Complexity: O(|s| * 26)
 * Space Complexity: O(|s|)
 */
public class Solution {
    private static final long LIMIT = 1_000_001L;

    public String smallestPalindrome(String s, int k) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }

        int[] half = new int[26];
        int len = 0;
        char middleChar = 0;

        // Step 1: Calculate character counts for the left half and locate middle character
        for (int i = 0; i < 26; i++) {
            half[i] = freq[i] / 2;
            len += half[i];
            if ((freq[i] & 1) == 1) {
                middleChar = (char) ('a' + i);
            }
        }

        // Step 2: Validate if total distinct palindromic permutations are >= k
        if (countWays(half, len) < k) {
            return "";
        }

        StringBuilder leftHalf = new StringBuilder();

        // Step 3: Construct the left half character-by-character
        for (int pos = 0; pos < len; pos++) {
            for (int ch = 0; ch < 26; ch++) {
                if (half[ch] == 0) continue;

                // Try placing character 'ch' at current position
                half[ch]--;
                long ways = countWays(half, len - pos - 1);

                if (ways >= k) {
                    leftHalf.append((char) ('a' + ch));
                    break; // Choice confirmed, move to next position
                }

                // Skip all permutations starting with 'ch'
                k -= ways;
                half[ch]++; // Backtrack
            }
        }

        // Step 4: Assemble left half + middle character + right half
        StringBuilder result = new StringBuilder();
        result.append(leftHalf);
        if (middleChar != 0) {
            result.append(middleChar);
        }
        result.append(new StringBuilder(leftHalf).reverse());

        return result.toString();
    }

    /**
     * Helper to compute distinct permutations of unused characters, capped at LIMIT.
     */
    private long countWays(int[] cnt, int total) {
        long ways = 1;
        int rem = total;

        for (int i = 0; i < 26; i++) {
            int c = cnt[i];
            if (c == 0) continue;

            // Compute combinations C(rem, c)
            int r = Math.min(c, rem - c);
            long comb = 1;
            for (int j = 1; j <= r; j++) {
                comb = comb * (rem - r + j) / j;
                if (comb >= LIMIT) {
                    comb = LIMIT;
                    break;
                }
            }

            ways = ways * comb;
            if (ways >= LIMIT) {
                return LIMIT;
            }

            rem -= c;
        }

        return ways;
    }
}
```
### 📊 Complexity Analysis

| Type | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(\|s\| \times |\Sigma|)$ | Building the left half requires placing $\frac{\|s\|}{2}$ characters. At each position, we check up to $|\Sigma| = 26$ lowercase English letters. The combination calculation early-exits in $\mathcal{O}(|\Sigma|)$ time due to the $10^6$ limit constraint. |
| **Space Complexity** | $\mathcal{O}(\|s\|)$ | Used to store character frequencies ($26$ integers) and build the left, right, and final resulting palindrome string. |
