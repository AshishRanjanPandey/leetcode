# 🚀 Maximum Product of Three Numbers

### 📝 Problem Description

Given an integer array `nums`, find three numbers whose product is maximum and return the **maximum product**.

---

### 💡 Intuition & Strategy

1. **Understanding the Mathematical Traps**:
   * If all numbers in the array are positive, the maximum product is simply the product of the **three largest numbers**.
   * If the array contains negative numbers, multiplying two large negative numbers produces a **large positive product**.
   * Therefore, the maximum product will always be the maximum of:
     1. The product of the three largest numbers: $\text{max1} \times \text{max2} \times \text{max3}$
     2. The product of the two smallest (most negative) numbers and the largest number: $\text{min1} \times \text{min2} \times \text{max1}$

2. **Single-Pass $O(N)$ Traversal**:
   * Instead of sorting the array in $O(N \log N)$ time, we can track the **three maximums** (`max1`, `max2`, `max3`) and **two minimums** (`min1`, `min2`) in a single pass.

3. **Updating the Extremes**:
   For each element `n` in `nums`:
   * **For Maximums**:
     * If `n > max1`: `max3` becomes `max2`, `max2` becomes `max1`, and `max1` becomes `n`.
     * Else if `n > max2`: `max3` becomes `max2`, and `max2` becomes `n`.
     * Else if `n > max3`: `max3` becomes `n`.
   * **For Minimums**:
     * If `n < min1`: `min2` becomes `min1`, and `min1` becomes `n`.
     * Else if `n < min2`: `min2` becomes `n`.

---

### 💻 Java Solution

```java
/**
 * Problem: Maximum Product of Three Numbers
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 */
public class Solution {

    public int maximumProduct(int[] nums) {
        int max1 = Integer.MIN_VALUE;
        int max2 = Integer.MIN_VALUE;
        int max3 = Integer.MIN_VALUE;

        int min1 = Integer.MAX_VALUE;
        int min2 = Integer.MAX_VALUE;

        for (int n : nums) {
            // Update top 3 maximums
            if (n > max1) {
                max3 = max2;
                max2 = max1;
                max1 = n;
            } else if (n > max2) {
                max3 = max2;
                max2 = n;
            } else if (n > max3) {
                max3 = n;
            }

            // Update top 2 minimums
            if (n < min1) {
                min2 = min1;
                min1 = n;
            } else if (n < min2) {
                min2 = n;
            }
        }

        return Math.max(max1 * max2 * max3, min1 * min2 * max1);
    }
}
```
### ⚡ Complexity Analysis

| Approach | Time Complexity | Space Complexity | Explanation |
| :--- | :--- | :--- | :--- |
| **Single-Pass (Optimal)** | $\mathcal{O}(N)$ | $\mathcal{O}(1)$ | Iterates through the array once to track the top 3 maximums and top 2 minimums using constant extra space. |
| **Sorting** | $\mathcal{O}(N \log N)$ | $\mathcal{O}(1)$ / $\mathcal{O}(\log N)$ | Sorting the array takes $\mathcal{O}(N \log N)$ time. Space complexity depends on the dual-pivot Quicksort implementation in Java (`Arrays.sort`). |
| **Min/Max Heap** | $\mathcal{O}(N)$ | $\mathcal{O}(1)$ | Maintaining a fixed-size heap of 3 elements for max values and 2 elements for min values takes $\mathcal{O}(N \log 3) = \mathcal{O}(N)$ time. |
