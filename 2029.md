# 🚀 Stone Game IX

### 📝 Problem Description

Alice and Bob continue their games with stones. There is a row of `n` stones, and each stone has an associated value given in the integer array `stones`.

Alice and Bob take turns, with Alice starting first:
- On each turn, the current player may remove any stone from `stones`.
- The player who removes a stone **loses** if the sum of the values of all removed stones is divisible by `3`.
- Bob will **win automatically** if there are no remaining stones (even if it is Alice's turn).

Assuming both players play optimally, return `true` if Alice wins and `false` if Bob wins.

---

### 💡 Intuition & Strategy

1. **Modulo 3 Simplification**:
   * The actual values of the stones do not matter; only their remainders modulo 3 determine the outcome.
   * Group stones by remainder modulo 3 into three counts:
     * `c0`: Count of stones with remainder `0` ($\text{stone} \pmod 3 == 0$)
     * `c1`: Count of stones with remainder `1` ($\text{stone} \pmod 3 == 1$)
     * `c2`: Count of stones with remainder `2` ($\text{stone} \pmod 3 == 2$)

2. **Role of Modulo 0 Stones (`c0`)**:
   * Taking a `0 mod 3` stone does not change the running sum modulo 3.
   * It effectively acts as a **turn-passing move**, shifting turn parity between Alice and Bob.

3. **Game Mechanics & Valid Sequences**:
   * Alice cannot start with a `0 mod 3` stone on Turn 1 (sum would be $0 \equiv 0 \pmod 3$, losing immediately).
   * **If Alice starts with a `1`**:
     * Current sum $\equiv 1 \pmod 3$.
     * Next non-zero move must be `1` (sum $\equiv 2$).
     * Next non-zero move must be `2` (sum $\equiv 1$), then `1`, then `2`, alternating: `[1, 1, 2, 1, 2, 1, 2, ...]`.
   * **If Alice starts with a `2`**:
     * Current sum $\equiv 2 \pmod 3$.
     * Alternating sequence becomes: `[2, 2, 1, 2, 1, 2, 1, ...]`.

4. **Case Breakdown**:
   * **Case 1: `c0` is even (`c0 % 2 == 0`)**:
     * An even number of `0`s cancels out and does not change the overall turn parity for non-zero moves.
     * Alice can win if there is at least one `1` and at least one `2` available:
       $$\text{Alice Wins} \iff c1 \ge 1 \land c2 \ge 1$$
   * **Case 2: `c0` is odd (`c0 % 2 == 1`)**:
     * An odd number of `0`s flips the turn advantage.
     * Alice needs a large disparity between `c1` and `c2` (specifically, more than 2) to force Bob into an invalid move or outlast the parity flip:
       $$\text{Alice Wins} \iff |c1 - c2| > 2$$

5. **Complexity**:
   * **Time Complexity**: **$O(N)$** — A single pass through `stones` to count remainders.
   * **Space Complexity**: **$O(1)$** — Uses a constant-size frequency array.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 */
public class Solution {

    public boolean stoneGameIX(int[] stones) {
        int[] count = new int[3];

        // Step 1: Count stones by their value modulo 3
        for (int stone : stones) {
            count[stone % 3]++;
        }

        int c0 = count[0];
        int c1 = count[1];
        int c2 = count[2];

        // Step 2: Determine outcome based on the parity of c0
        if (c0 % 2 == 0) {
            // If c0 is even, Alice wins if both remainder 1 and remainder 2 stones exist
            return c1 >= 1 && c2 >= 1;
        } else {
            // If c0 is odd, Alice wins only if the absolute difference between c1 and c2 is > 2
            return Math.abs(c1 - c2) > 2;
        }
    }
}
```

| **Space Complexity** | $\mathcal{O}(1)$ | Uses a fixed-size frequency array of length 3, requiring constant auxiliary memory. |
