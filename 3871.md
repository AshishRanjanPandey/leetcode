# 🎯 LeetCode: Count Commas in Numbers Up to N

### 📝 Problem Description

You are given an integer `n`. Return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

In standard number formatting:
- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

**Example 1:**
- **Input:** `n = 1002`
- **Output:** `3`
- **Explanation:**
  The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma, giving a total of $3$.

**Example 2:**
- **Input:** `n = 998`
- **Output:** `0`
- **Explanation:**
  All numbers from $1$ to $998$ have fewer than four digits. Therefore, no commas are used.

**Constraints:**
- $1 \le n \le 10^{15}$

---

### 💡 Intuition & Strategy

1. **Threshold Analysis**:
   - Integers from $1$ to $999$ have $1$ to $3$ digits and require **$0$ commas**.
   - Integers from $1,000$ to $999,999$ have $4$ to $6$ digits and require **$1$ comma** each.
   - Integers from $1,000,000$ to $999,999,999$ have $7$ to $9$ digits and require **$2$ commas** each.
   - Integers from $10^{3k}$ onward require at least $k$ commas.

2. **Prefix / Contribution Technique**:
   - Instead of computing how many commas each individual number requires, sum the contributions of each comma milestone $T = 10^{3k}$:
     - Every number $\ge 10^3$ ($1,000$) adds its **$1\text{st}$ comma**.
     - Every number $\ge 10^6$ ($1,000,000$) adds its **$2\text{nd}$ comma**.
     - Every number $\ge 10^9$ ($1,000,000,000$) adds its **$3\text{rd}$ comma**, and so on.
   - For a given threshold $T$, if $n \ge T$, exactly $(n - T + 1)$ numbers are greater than or equal to $T$, contributing $(n - T + 1)$ commas.

3. **Handling Large Constraints ($n \le 10^{15}$)**:
   - Use standard 64-bit integers (`long` in Java) to prevent numeric overflow.
   - The loop checks milestones $10^3, 10^6, 10^9, 10^{12}, 10^{15}$ and terminates in at most $5$ iterations.

4. **Complexity**:
   - **Time Complexity**: $O(\log_{1000} n) \approx O(1)$ — At most $5$ iterations for $n \le 10^{15}$.
   - **Space Complexity**: $O(1)$ — Constant auxiliary space.

---

### 💻 Java Solution

```java
/**
 * Problem: Count Commas in Numbers Up to N
 * Language: Java 17 / 21
 * Time Complexity: O(log1000(n)) ≈ O(1)
 * Space Complexity: O(1)
 */
class Solution {

    public long countCommas(long n) {
        long totalCommas = 0;
        long threshold = 1000L; // 10^3

        while (n >= threshold) {
            totalCommas += (n - threshold + 1);

            // Guard against 64-bit integer overflow before scaling up
            if (threshold > Long.MAX_VALUE / 1000L) {
                break;
            }
            threshold *= 1000L;
        }

        return totalCommas;
    }
}
