# 🎯 LeetCode: Count Commas in Numbers Up to N

### 📝 Problem Description

You are given an integer `n`. Return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

In standard number formatting:
- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

**Example 1:**
- **Input:** `n = 1002`
- **Output:** `3`
- **Explanation:**
  The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma, giving a total of $3$.

**Example 2:**
- **Input:** `n = 998`
- **Output:** `0`
- **Explanation:**
  All numbers from $1$ to $998$ have fewer than four digits. Therefore, no commas are used.

**Constraints:**
- $1 \le n \le 10^5$

---

### 💡 Intuition & Strategy

1. **Threshold Analysis**:
   - Integers from $1$ to $999$ have $1$ to $3$ digits and require **$0$ commas**.
   - Integers from $1,000$ to $999,999$ have $4$ to $6$ digits and require **$1$ comma** each.
   - Integers from $1,000,000$ to $999,999,999$ have $7$ to $9$ digits and require **$2$ commas** each, and so on.

2. **Constraint Exploitation ($n \le 10^5$)**:
   - The maximum possible value is $n = 100,000$.
   - Since $100,000 < 1,000,000$, every number in the range that contains any comma at all will contain **exactly 1 comma**.
   - Thus:
     - If $n < 1000$, total commas = $0$.
     - If $n \ge 1000$, total commas = $n - 1000 + 1 = n - 999$.

3. **Generalization for Arbitrary $N$**:
   - For unrestricted $n$, each milestone $10^{3k}$ (e.g., $1,000$, $1,000,000$, $1,000,000,000$) adds an additional comma to every integer greater than or equal to that milestone.
   - Total commas can be computed by summing $(n - 10^{3k} + 1)$ for all $10^{3k} \le n$.

4. **Complexity**:
   - **Time Complexity**: $O(1)$ — Direct arithmetic evaluation.
   - **Space Complexity**: $O(1)$ — No additional memory required.

---

### 💻 Java Solution

```java
/**
 * Problem: Count Commas in Numbers Up to N
 * Language: Java 17
 * Time Complexity: O(1)
 * Space Complexity: O(1)
 */
class Solution {

    public int countCommas(int n) {
        // Numbers below 1,000 use 0 commas.
        // Under n <= 10^5, every number >= 1,000 contains exactly 1 comma.
        return Math.max(0, n - 999);
    }
}
