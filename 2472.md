# 🚀 LeetCode 2472 — Maximum Number of Non-overlapping Palindrome Substrings

### 📝 Problem Description
You are given a string `s` and a positive integer `k`.

Select a set of non-overlapping substrings from the string `s` such that:
1. The length of each substring is at least `k`.
2. Each substring is a palindrome.

Return the maximum number of substrings in an optimal selection.

---

### 💡 Intuition & Approach
Any palindrome of length $L \ge k + 2$ contains a smaller centered sub-palindrome of length $L - 2$. By induction, any valid palindrome of length at least $k$ contains a smaller palindrome of length either **$k$** or **$k + 1$**.

To maximize the count of non-overlapping substrings, finding shorter valid palindromes as early as possible leaves maximum space for future palindromes. Hence, a greedy scan checking for palindromes of length $k$ or $k + 1$ ending at each position gives the optimal result.

---

### 💻 Java Solution

```java
/**
 * Problem: Maximum Number of Non-overlapping Palindrome Substrings (LeetCode 2472)
 * Language: Java 17
 */
class Solution {
    public int maxPalindromes(String s, int k) {
        int n = s.length();
        int count = 0;
        int lastEnd = -1; // End index of the last selected palindrome

        // Step 1: Iterate over each possible end position
        for (int i = 0; i < n; i++) {
            // Check for a palindrome of length k ending at index i
            int startK = i - k + 1;
            if (startK > lastEnd && isPalindrome(s, startK, i)) {
                count++;
                lastEnd = i;
                continue;
            }

            // Check for a palindrome of length (k + 1) ending at index i
            int startK1 = i - (k + 1) + 1;
            if (startK1 > lastEnd && isPalindrome(s, startK1, i)) {
                count++;
                lastEnd = i;
            }
        }

        return count;
    }

    // Helper method to verify if a substring s[left...right] is a palindrome
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :--- | :--- |
| **Time Complexity** | $O(N \cdot k)$ | We traverse the string of length $N$ once. At each index, we check at most two potential palindromes of length $k$ and $k + 1$, each taking $O(k)$ operations. |
| **Space Complexity** | $O(1)$ | No additional memory, lookup arrays, or recursion stacks are allocated; only a few primitive integer pointers are maintained. |
| **Worst-Case Time** | $O(N \cdot k)$ | Occurs when character matches frequently reach the full length check before terminating (e.g., all identical characters). |
| **Best-Case Time** | $O(N)$ | Occurs when mismatch checks fail immediately on the outermost character comparison in $O(1)$. |
