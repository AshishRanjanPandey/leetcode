# 🚀 Stone Game (LeetCode 877)

### 📝 Problem Description

There are an even number of piles arranged in a row, and each pile has a positive integer number of stones `piles[i]`.

The objective of the game is to end with the most stones. The total number of stones across all the piles is odd, so there are no ties.

Alice and Bob take turns, with Alice starting first. Each turn, a player takes the entire pile of stones either from the beginning or from the end of the row. This continues until there are no more piles left, at which point the person with the most stones wins.

Assuming Alice and Bob play optimally, return `true` if Alice wins the game, or `false` if Bob wins.

---

### 💡 Intuition & Strategy

1. **Net Score Difference Advantage**:
   * Instead of tracking individual scores for Alice and Bob, we track the **relative score difference** (Alice's points minus Bob's points) for any continuous subarray of piles `piles[i...j]`.
   * A positive result indicates that the first player to act on that subarray can secure more stones than the second player.

2. **Minimax Recurrence**:
   * If the current player picks `piles[i]`, their score advantage becomes:
     $$\text{piles}[i] - \text{dp}(i + 1, j)$$
   * If the current player picks `piles[j]`, their score advantage becomes:
     $$\text{piles}[j] - \text{dp}(i, j - 1)$$
   * Both players play optimally using `Math.max` to choose the move that maximizes their relative advantage:
     $$\text{dp}(i, j) = \max\Big(\text{piles}[i] - \text{dp}(i + 1, j),\; \text{piles}[j] - \text{dp}(i, j - 1)\Big)$$

3. **$O(1)$ Mathematical Proof**:
   * Since `piles.length` is strictly **even** and the total sum of stones is **odd**, Alice can always choose to pick *all even-indexed piles* or *all odd-indexed piles*.
   * Alice calculates which set has a larger sum before making her first move and forces Bob into picking from the other parity set on every turn, guaranteeing her victory in $O(1)$ time.

### 💻 Java Solutions

#### Solution 1: Dynamic Programming ($O(N^2)$ Time, $O(N)$ Space)

```java
/**
 * Problem: Stone Game (LeetCode 877)
 * Language: Java 17
 * Time Complexity: O(N^2) where N = |piles|
 * Space Complexity: O(N) using 1D DP optimization
 */
public class Solution {

    public boolean stoneGame(int[] piles) {
        int n = piles.length;

        // dp[j] stores the max relative score advantage for subarray piles[i...j]
        int[] dp = new int[n];

        // Base cases: Subarrays of length 1
        for (int i = 0; i < n; i++) {
            dp[i] = piles[i];
        }

        // Process subproblems from bottom-up
        for (int i = n - 2; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                int pickLeft = piles[i] - dp[j];
                int pickRight = piles[j] - dp[j - 1];
                dp[j] = Math.max(pickLeft, pickRight);
            }
        }

        // Alice wins if relative score advantage over the full range is > 0
        return dp[n - 1] > 0;
    }
}
```
### 📊 Complexity Analysis

| Approach | Time Complexity | Space Complexity | Explanation |
| :--- | :--- | :--- | :--- |
| **Mathematical Strategy** | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ | Instant constant time result; leverages parity guarantee (even length, odd total sum). |
| **1D Space-Optimized DP** | $\mathcal{O}(N^2)$ | $\mathcal{O}(N)$ | Evaluates all $N(N+1)/2$ interval subproblems using a single array of size $N$. |
| **2D Interval DP** | $\mathcal{O}(N^2)$ | $\mathcal{O}(N^2)$ | Computes states for every subarray range $[i \dots j]$ using an $N \times N$ matrix. |
| **Two-Pointer / Greedy** | $\mathcal{O}(N)$ | $\mathcal{O}(1)$ | ❌ **Incorrect Strategy** — Fails to look ahead and misses optimal opponent moves. |
