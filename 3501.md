# 🚀 LeetCode 3501 — Maximize Active Section With Trade II

### 📝 Problem Description

You are given a binary string `s` of length `n`, where:
* `'1'` represents an active section.
* `'0'` represents an inactive section.

You can perform **at most one trade** to maximize the number of active sections in `s`. In a trade, you:
1. Convert a contiguous block of `'1'`s that is surrounded by `'0'`s to all `'0'`s.
2. Afterward, convert a contiguous block of `'0'`s that is surrounded by `'1'`s to all `'1'`s.

Additionally, you are given a 2D array `queries`, where `queries[i] = [li, ri]` represents a substring `s[li...ri]`.

For each query, determine the maximum possible number of active sections in `s` after making the optimal trade on the substring `s[li...ri]`.

> **Note:** For each query, treat `s[li...ri]` as if it is augmented with a `'1'` at both ends, forming $t = \text{"1"} + s[li...ri] + \text{"1"}$. The augmented `'1'`s do not contribute to the final count. The queries are independent of each other.

---

### 💡 Intuition & Strategy

1. **Trade Mechanics**:
   Converting a block of `'1'`s $B_i$ inside `s[l...r]` to `'0'`s merges the surrounding zero regions into one unified zero region. Flipping that combined zero block yields a net gain of ones:
   $$\text{gain} = \text{pos}(\text{next\_1}) - \text{pos}(\text{prev\_1}) - 1 - \text{len}(B_i)$$

2. **Query Classification**:
   For a query range `[l, r]`, we identify all `'1'`-blocks strictly contained inside `[l, r]` (i.e., `start > l` and `end < r`):
   * **Boundary Blocks ($B_{\text{first}}$ and $B_{\text{last}}$)**: Their bounding '1's may extend to the augmented edges ($l-1$ or $r+1$). Their gains are calculated dynamically in $O(1)$ time.
   * **Middle Internal Blocks**: Their adjacent zero boundaries are fixed relative to the original string. We precompute their static gains and query the range maximum in $O(1)$ using a **Sparse Table**.

3. **Binary Search**:
   Use binary search (`lowerBound` / `upperBound`) to find $B_{\text{first}}$ and $B_{\text{last}}$ in $O(\log M)$ time per query.

4. **Total Active Count**:
   The trade modifies only the query substring, so the total active sections after an optimal trade is:
   $$\text{Total Active} = \text{totalOnes}(s) + \max(0, \text{maxGain})$$

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.List;

/**
 * Problem: Maximize Active Section With Trade II
 * Language: Java 17
 */
public class Solution {

    static class Block {
        int start, end, len;
        Block(int start, int end) {
            this.start = start;
            this.end = end;
            this.len = end - start + 1;
        }
    }

    public List<Integer> maxActiveSectionsAfterTrade(String s, int[][] queries) {
        int n = s.length();
        int totalOnes = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                totalOnes++;
            }
        }

        // Step 1: Identify all maximal contiguous blocks of '1's
        List<Block> blocks = new ArrayList<>();
        int i = 0;
        while (i < n) {
            if (s.charAt(i) == '1') {
                int start = i;
                while (i < n && s.charAt(i) == '1') {
                    i++;
                }
                blocks.add(new Block(start, i - 1));
            } else {
                i++;
            }
        }

        int m = blocks.size();
        int[] startArr = new int[m];
        int[] endArr = new int[m];
        for (int k = 0; k < m; k++) {
            startArr[k] = blocks.get(k).start;
            endArr[k] = blocks.get(k).end;
        }

        // Step 2: Precompute static gains for internal blocks
        int[] staticGain = new int[m];
        for (int k = 1; k < m - 1; k++) {
            staticGain[k] = blocks.get(k + 1).start - blocks.get(k - 1).end - 1 - blocks.get(k).len;
        }

        // Step 3: Build Sparse Table for Range Maximum Queries
        int[][] st = buildSparseTable(staticGain, m);

        List<Integer> ans = new ArrayList<>(queries.length);

        // Step 4: Process queries
        for (int[] query : queries) {
            int l = query[0];
            int r = query[1];

            int first = lowerBound(startArr, l + 1);
            int last = upperBound(endArr, r - 1);

            int maxGain = 0;

            if (first <= last && first < m && last >= 0) {
                if (first == last) {
                    int pPrev = (first > 0) ? Math.max(l - 1, blocks.get(first - 1).end) : l - 1;
                    int pNext = (last < m - 1) ? Math.min(r + 1, blocks.get(last + 1).start) : r + 1;
                    maxGain = pNext - pPrev - 1 - blocks.get(first).len;
                } else {
                    // Gain for the first block
                    int pPrevFirst = (first > 0) ? Math.max(l - 1, blocks.get(first - 1).end) : l - 1;
                    int pNextFirst = blocks.get(first + 1).start;
                    int gFirst = pNextFirst - pPrevFirst - 1 - blocks.get(first).len;

                    // Gain for the last block
                    int pPrevLast = blocks.get(last - 1).end;
                    int pNextLast = (last < m - 1) ? Math.min(r + 1, blocks.get(last + 1).start) : r + 1;
                    int gLast = pNextLast - pPrevLast - 1 - blocks.get(last).len;

                    maxGain = Math.max(gFirst, gLast);

                    // Gain for middle blocks via Sparse Table
                    if (first + 1 <= last - 1) {
                        int gMid = queryRMQ(st, first + 1, last - 1);
                        maxGain = Math.max(maxGain, gMid);
                    }
                }
            }

            ans.add(totalOnes + Math.max(0, maxGain));
        }

        return ans;
    }

    private int lowerBound(int[] arr, int target) {
        int low = 0, high = arr.length - 1;
        int ans = arr.length;
        while (low <= high) {
            int mid = (low + high) >>> 1;
            if (arr[mid] >= target) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }

    private int upperBound(int[] arr, int target) {
        int low = 0, high = arr.length - 1;
        int ans = -1;
        while (low <= high) {
            int mid = (low + high) >>> 1;
            if (arr[mid] <= target) {
                ans = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        return ans;
    }

    private int[][] buildSparseTable(int[] arr, int n) {
        if (n == 0) return new int[0][0];
        int logN = 32 - Integer.numberOfLeadingZeros(n);
        int[][] st = new int[logN][n];
        System.arraycopy(arr, 0, st[0], 0, n);

        for (int i = 1; i < logN; i++) {
            for (int j = 0; j + (1 << i) <= n; j++) {
                st[i][j] = Math.max(st[i - 1][j], st[i - 1][j + (1 << (i - 1))]);
            }
        }
        return st;
    }

    private int queryRMQ(int[][] st, int L, int R) {
        int len = R - L + 1;
        int k = 31 - Integer.numberOfLeadingZeros(len);
        return Math.max(st[k][L], st[k][R - (1 << k) + 1]);
    }
}
```

### ⏱️ Complexity Analysis

| Section | Operation | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- |
| **Parsing** | String Augmentation & Block Extraction | $\mathcal{O}(N)$ | $\mathcal{O}(K)$ |
| **Preprocessing** | Prefix & Suffix Max Arrays | $\mathcal{O}(K)$ | $\mathcal{O}(K)$ |
| **Evaluation** | Trade Choice Iteration | $\mathcal{O}(K)$ | $\mathcal{O}(1)$ |
| **Overall** | **Total Complexity** | $\mathbf{\mathcal{O}(N)}$ | $\mathbf{\mathcal{O}(N)}$ |

> **Variables:**  
> - $N = |s|$ (Length of the binary string $s$)  
> - $K \le \lceil (N + 2)/2 \rceil$ (Total number of contiguous `'1'` blocks in $t$)
