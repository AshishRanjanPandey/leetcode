# 🚀 LeetCode 1621 — Number of Sets of K Non-Overlapping Line Segments

### 📝 Problem Description
Given `n` points on a 1-D plane, where the $i$-th point (from `0` to `n - 1`) is at `x = i`, find the number of ways we can draw exactly `k` non-overlapping line segments such that each segment covers two or more points. 

The endpoints of each segment must have integral coordinates. The `k` line segments do not have to cover all `n` points, and they are allowed to share endpoints.

Return the number of ways we can draw `k` non-overlapping line segments modulo $10^9 + 7$.

---

### 💻 Java Solution

```java
/**
 * Problem: Number of Sets of K Non-Overlapping Line Segments (LeetCode 1621)
 * Language: Java 17
 */
class Solution {
    private static final int MOD = 1_000_000_007;

    public int numberOfSets(int n, int k) {
        // Combinatorics Approach:
        // Choosing k segments where adjacent segments can share endpoints
        // maps directly to choosing 2k points out of (n + k - 1) positions:
        // C(n + k - 1, 2 * k) mod (10^9 + 7)
        int N = n + k - 1;
        int R = 2 * k;

        if (R > N) return 0;
        
        // Optimize using symmetry property: C(n, r) == C(n, n - r)
        if (R > N - R) {
            R = N - R;
        }

        long numerator = 1;
        long denominator = 1;

        // Compute C(N, R) % MOD using modular inverse
        for (int i = 1; i <= R; i++) {
            numerator = (numerator * (N - i + 1)) % MOD;
            denominator = (denominator * i) % MOD;
        }

        return (int) ((numerator * modInverse(denominator, MOD)) % MOD);
    }

    // Fermat's Little Theorem to find modular multiplicative inverse: a^(MOD - 2) % MOD
    private long modInverse(long base, int mod) {
        return power(base, mod - 2, mod);
    }

    // Binary exponentiation for fast power computation
    private long power(long base, long exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) {
                result = (result * base) % mod;
            }
            base = (base * base) % mod;
            exp >>= 1;
        }
        return result;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Details |
| :--- | :--- | :--- |
| **Time Complexity** | $O(k + \log(\text{MOD}))$ | The combination loop runs in at most $2k$ iterations ($O(k)$), followed by modular inverse via binary exponentiation taking $O(\log(\text{MOD}))$ time. |
| **Auxiliary Space** | $O(1)$ | Operates purely in-place using a few scalar `long` variables without any dynamic arrays, lookup tables, or recursion call frames. |
