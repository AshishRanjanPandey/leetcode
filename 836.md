# 🚀 LeetCode 836 — Rectangle Overlap

### 📝 Problem Description
An axis-aligned rectangle is represented as a list `[x1, y1, x2, y2]`, where `(x1, y1)` is the coordinate of its bottom-left corner, and `(x2, y2)` is the coordinate of its top-right corner. Its top and bottom edges are parallel to the X-axis, and its left and right edges are parallel to the Y-axis.

Two rectangles overlap if the area of their intersection is positive. To be clear, two rectangles that only touch at the corner or edges do not overlap.

Given two axis-aligned rectangles `rec1` and `rec2`, return `true` if they overlap, otherwise return `false`.

---

### 💻 Java Solution

```java
/**
 * Problem: Rectangle Overlap (LeetCode 836)
 * Language: Java 17
 */
class Solution {
    public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
        // A rectangle is represented as [x1, y1, x2, y2]
        // Two rectangles overlap if and only if their 1D projections 
        // on both the X-axis and Y-axis overlap with positive length.
        
        // Check overlap along the X-axis:
        // rec1's left edge must be to the left of rec2's right edge AND
        // rec2's left edge must be to the left of rec1's right edge.
        boolean xOverlap = rec1[0] < rec2[2] && rec2[0] < rec1[2];
        
        // Check overlap along the Y-axis:
        // rec1's bottom edge must be below rec2's top edge AND
        // rec2's bottom edge must be below rec1's top edge.
        boolean yOverlap = rec1[1] < rec2[3] && rec2[1] < rec1[3];
        
        // Both projections must overlap for a positive intersection area
        return xOverlap && yOverlap;
    }
}
```
| Metric | Complexity | Details |
| :--- | :--- | :--- |
| **Best Case Time** | $O(1)$ | Direct coordinate comparison with short-circuit evaluation terminates on the first `false` condition. |
| **Worst Case Time** | $O(1)$ | Performs at most 4 boundary comparisons regardless of coordinate magnitude. |
| **Average Case Time** | $O(1)$ | Fixed number of scalar comparison instructions executed in constant CPU cycles. |
| **Auxiliary Space** | $O(1)$ | Only two primitive boolean variables (`xOverlap`, `yOverlap`) allocated on the stack. |
| **Total Space** | $O(1)$ | Operates directly on the input arrays with no dynamic memory allocation. |
