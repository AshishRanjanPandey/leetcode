# 🚀 Longest Substring of One Repeating Character

### 📝 Problem Description

You are given a 0-indexed string `s`. You are also given a 0-indexed string `queryCharacters` of length `k` and a 0-indexed array of integer indices `queryIndices` of length `k`, both of which are used to describe `k` queries.

The $i^{\text{th}}$ query updates the character in `s` at index `queryIndices[i]` to the character `queryCharacters[i]`.

Return an array `lengths` of length `k` where `lengths[i]` is the length of the longest substring of `s` consisting of only one repeating character after the $i^{\text{th}}$ query is performed.

---

### 💡 Intuition & Strategy

1. **Segment Tree for Dynamic Range Queries**:
   * Since $N$ (length of string) and $K$ (number of queries) are up to $10^5$, scanning the string after each update takes $O(N)$ per query, leading to $O(N \times K)$ total time (which will TLE).
   * We can manage point updates and track the global maximum repeating character sequence efficiently in **$O(\log N)$** per query using a **Segment Tree**.

2. **Node Information & State**:
   Each segment tree node representing interval $[L, R]$ maintains five parameters:
   * `maxLen`: Length of the longest repeating substring within $[L, R]$.
   * `prefLen`: Length of the longest repeating prefix starting at index $L$.
   * `suffLen`: Length of the longest repeating suffix ending at index $R$.
   * `leftChar`: Character at index $L$.
   * `rightChar`: Character at index $R$.

3. **Segment Tree Merge Logic**:
   When combining a left child $[L, \text{mid}]$ and a right child $[\text{mid} + 1, R]$:
   * **Boundary Match**: If `left.rightChar == right.leftChar`, a contiguous repeating sequence crosses the midpoint of length `left.suffLen + right.prefLen`.
   * **Max Length**: `maxLen = max(left.maxLen, right.maxLen, combined_mid_length)`.
   * **Prefix Length**: Inherits `left.prefLen`. If the left child is fully uniform (`left.prefLen == leftSpan`) and matches `right.leftChar`, it extends into `right.prefLen`.
   * **Suffix Length**: Inherits `right.suffLen`. If the right child is fully uniform (`right.suffLen == rightSpan`) and matches `left.rightChar`, it extends into `left.suffLen`.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(N + K log N)
 * Space Complexity: O(N) auxiliary space for the Segment Tree
 */
public class Solution {

    static class SegmentTree {
        private final int n;
        private final int[] maxLen;
        private final int[] prefLen;
        private final int[] suffLen;
        private final char[] leftChar;
        private final char[] rightChar;

        public SegmentTree(String s) {
            this.n = s.length();
            int size = 4 * n;
            maxLen = new int[size];
            prefLen = new int[size];
            suffLen = new int[size];
            leftChar = new char[size];
            rightChar = new char[size];

            build(0, 0, n - 1, s.toCharArray());
        }

        private void merge(int node, int l, int r, int mid) {
            int leftChild = 2 * node + 1;
            int rightChild = 2 * node + 2;

            leftChar[node] = leftChar[leftChild];
            rightChar[node] = rightChar[rightChild];

            int leftSpan = mid - l + 1;
            int rightSpan = r - mid;

            // Base prefix and suffix lengths
            prefLen[node] = prefLen[leftChild];
            suffLen[node] = suffLen[rightChild];

            // Extend prefix if left segment is entirely uniform and matches right child start
            if (prefLen[leftChild] == leftSpan && leftChar[leftChild] == leftChar[rightChild]) {
                prefLen[node] = leftSpan + prefLen[rightChild];
            }

            // Extend suffix if right segment is entirely uniform and matches left child end
            if (suffLen[rightChild] == rightSpan && rightChar[rightChild] == rightChar[leftChild]) {
                suffLen[node] = rightSpan + suffLen[leftChild];
            }

            // Calculate overall maximum length
            maxLen[node] = Math.max(maxLen[leftChild], maxLen[rightChild]);

            // Check if boundary characters match across midpoint
            if (rightChar[leftChild] == leftChar[rightChild]) {
                maxLen[node] = Math.max(maxLen[node], suffLen[leftChild] + prefLen[rightChild]);
            }
        }

        private void build(int node, int l, int r, char[] s) {
            if (l == r) {
                maxLen[node] = 1;
                prefLen[node] = 1;
                suffLen[node] = 1;
                leftChar[node] = s[l];
                rightChar[node] = s[l];
                return;
            }

            int mid = l + (r - l) / 2;
            build(2 * node + 1, l, mid, s);
            build(2 * node + 2, mid + 1, r, s);
            merge(node, l, r, mid);
        }

        public void update(int node, int l, int r, int idx, char ch) {
            if (l == r) {
                leftChar[node] = ch;
                rightChar[node] = ch;
                return;
            }

            int mid = l + (r - l) / 2;
            if (idx <= mid) {
                update(2 * node + 1, l, mid, idx, ch);
            } else {
                update(2 * node + 2, mid + 1, r, idx, ch);
            }

            merge(node, l, r, mid);
        }

        public int getMax() {
            return maxLen[0];
        }
    }

    public int[] longestRepeating(String s, String queryCharacters, int[] queryIndices) {
        int k = queryIndices.length;
        int[] ans = new int[k];

        SegmentTree tree = new SegmentTree(s);

        for (int i = 0; i < k; i++) {
            int idx = queryIndices[i];
            char ch = queryCharacters.charAt(i);

            tree.update(0, 0, s.length() - 1, idx, ch);
            ans[i] = tree.getMax();
        }

        return ans;
    }
}
```
### ⏱️ Complexity Analysis

| Operation / Resource | Time / Space Complexity | Description |
| :--- | :--- | :--- |
| **Tree Construction** | $O(N)$ | Building the segment tree initially processes $2N - 1$ total nodes. |
| **Single Update Query** | $O(\log N)$ | Traverses down the height of the segment tree to update one character. |
| **Total Time Complexity** | **$O(N + K \log N)$** | $O(N)$ to build the tree plus $O(K \log N)$ for performing $K$ queries. |
| **Auxiliary Space** | **$O(N)$** | The segment tree arrays require at most $4N$ nodes in memory. |
