# 🚀 Unique XOR Triplets Count

### 📝 Problem Description

You are given an integer array `nums`.

A **XOR triplet** is defined as the XOR sum of three elements `nums[i] XOR nums[j] XOR nums[k]` where `i <= j <= k`.

Return the number of unique XOR triplet values from all possible triplets `(i, j, k)`.

---

### 💡 Intuition & Strategy

1. **Upper Bound & Bitwise Space**:
   Since $1 \le \text{nums}[i] \le 1500$, the maximum possible value of any element is $1500$, which fits within $11$ bits ($2^{11} - 1 = 2047$). Therefore, any bitwise XOR operation of these values will also stay strictly bounded within $[0, 2047]$.

2. **Step-by-Step Reduction ($O(U^2)$)**:
   * **Deduplication**: First, identify all unique values present in `nums`. Since $i, j, k$ can be identical, choosing $i = j = k$ yields the original element $\text{nums}[i] \oplus \text{nums}[i] \oplus \text{nums}[i] = \text{nums}[i]$, while $i = j < k$ yields $\text{nums}[k]$.
   * **Pairwise XORs**: Generate all unique pairwise XOR values $\text{nums}[i] \oplus \text{nums}[j]$ for all unique pairs $(i, j)$.
   * **Triplet XORs**: Combine each unique pair XOR with every unique original element to compute all reachable triplet XORs.

3. **Performance Optimization via Boolean Array**:
   Using `boolean[]` lookup tables bounded by $2048$ instead of heavy data structures like `HashSet` optimizes runtime to $\mathcal{O}(1)$ space overhead and minimal execution time ($\approx 1\text{ms}$).

---

### 💻 Java Solution

```java
/**
 * Problem: Unique XOR Triplets Count
 * Language: Java 17
 */
public class Solution {

    public int uniqueXorTriplets(int[] nums) {
        // Step 1: Track unique elements in nums.
        // Upper bound for nums[i] is 1500, so XOR values won't exceed 2047 (2^11 - 1).
        boolean[] hasNum = new boolean[2048];
        for (int num : nums) {
            hasNum[num] = true;
        }

        // Step 2: Compute all unique pairwise XOR values.
        boolean[] pairXor = new boolean[2048];
        for (int i = 0; i < 2048; i++) {
            if (hasNum[i]) {
                for (int j = i; j < 2048; j++) {
                    if (hasNum[j]) {
                        pairXor[i ^ j] = true;
                    }
                }
            }
        }

        // Step 3: Combine pair XORs with single elements to obtain triplet XORs.
        boolean[] tripletXor = new boolean[2048];
        int uniqueCount = 0;

        for (int i = 0; i < 2048; i++) {
            if (pairXor[i]) {
                for (int j = 0; j < 2048; j++) {
                    if (hasNum[j]) {
                        int currentXor = i ^ j;
                        if (!tripletXor[currentXor]) {
                            tripletXor[currentXor] = true;
                            uniqueCount++;
                        }
                    }
                }
            }
        }

        return uniqueCount;
    }
}
```
### ⏱️ Complexity Analysis

| Parameter | Complexity | Details |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(U^2)$ | $U \le 1500$ represents the count of unique values in `nums`. Bounded iterations ($2048 \times 2048$) over primitive boolean arrays execute in under $2\text{ms}$. |
| **Space Complexity** | $\mathcal{O}(1)$ | Fixed-size boolean arrays of size $2048$ ($2^{11}$) are used to keep track of set elements, consuming negligible static auxiliary memory. |
