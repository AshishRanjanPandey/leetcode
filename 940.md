# 🎯 LeetCode: Distinct Subsequences II

### 📝 Problem Description

Given a string `s`, return the number of distinct non-empty subsequences of `s`. Since the answer may be very large, return it modulo $10^9 + 7$.

A **subsequence** of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters (i.e., `"ace"` is a subsequence of `"abcde"` while `"aec"` is not).

**Example 1:**
- **Input:** `s = "abc"`
- **Output:** `7`
- **Explanation:**
  The 7 distinct subsequences are `"a"`, `"b"`, `"c"`, `"ab"`, `"ac"`, `"bc"`, and `"abc"`.

**Example 2:**
- **Input:** `s = "aba"`
- **Output:** `6`
- **Explanation:**
  The 6 distinct subsequences are `"a"`, `"b"`, `"ab"`, `"aa"`, `"ba"`, and `"aba"`.

**Example 3:**
- **Input:** `s = "aaa"`
- **Output:** `3`
- **Explanation:**
  The 3 distinct subsequences are `"a"`, `"aa"`, and `"aaa"`.

**Constraints:**
- $1 \le s.\text{length}() \le 2000$
- `s` consists of lowercase English letters.

---

### 💡 Intuition & Strategy

1. **Subproblem & State Definition**:
   - Let `currentTotal` be the total count of distinct non-empty subsequences formed using characters scanned so far.
   - Let `endWith[c]` denote the total count of distinct subsequences ending specifically with the character `c`.

2. **Appended Subsequences**:
   - When processing a new character `c`, it can be appended to:
     - Every existing distinct non-empty subsequence (`currentTotal` possibilities).
     - An empty subsequence to form the single-character string `c` ($1$ possibility).
   - Thus, the total distinct subsequences ending with `c` up to the current point is:
     $$\text{newSubseqForChar} = (\text{currentTotal} + 1) \pmod{10^9 + 7}$$

3. **Transitions & Deduplication**:
   - If character `c` occurred earlier, any previous subsequence ending with `c` (`endWith[c]`) was already accounted for.
   - To prevent duplicate counting, compute the net new subsequences contributed by `c`:
     $$\Delta = \text{newSubseqForChar} - \text{endWith}[c]$$
   - Update the global total and ending state:
     $$\text{currentTotal} = (\text{currentTotal} + \text{newSubseqForChar} - \text{endWith}[c] + \text{MOD}) \pmod{\text{MOD}}$$
     $$\text{endWith}[c] = \text{newSubseqForChar}$$

4. **Modulo Arithmetic Handling**:
   - Because subtraction $(\text{currentTotal} - \text{endWith}[c])$ can yield a negative result, we add `MOD` before applying the modulo operator.

5. **Complexity**:
   - **Time Complexity**: $O(n)$ — Single linear pass over string `s` of length $n$, executing constant-time $O(1)$ operations per character.
   - **Space Complexity**: $O(1)$ — Array `endWith` has a fixed size of $26$ regardless of input size $n$.

---

### 💻 Java Solution

```java
/**
 * Problem: Distinct Subsequences II
 * Language: Java 17
 * Time Complexity: O(n)
 * Space Complexity: O(1)
 */
class Solution {

    public int distinctSubseqII(String s) {
        final int MOD = 1_000_000_007;

        // endWith[i] stores the count of distinct subsequences ending with ('a' + i)
        long[] endWith = new long[26];
        long currentTotal = 0;

        // Step 1: Traverse through each character in string s
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';

            // Distinct subsequences ending at current character:
            // Append current char to all previous subsequences + single-character string
            long newSubseqForChar = (currentTotal + 1) % MOD;

            // Step 2: Update currentTotal with net new additions (avoiding duplicates)
            currentTotal = (currentTotal + newSubseqForChar - endWith[idx] + MOD) % MOD;

            // Step 3: Record updated count for this ending character
            endWith[idx] = newSubseqForChar;
        }

        // Step 4: Return total distinct non-empty subsequences
        return (int) currentTotal;
    }
}
