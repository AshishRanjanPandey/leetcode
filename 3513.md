# 🚀 Unique XOR Triplets Count

### 📝 Problem Description

You are given an integer array `nums` of length `n`, where `nums` is a permutation of the numbers in the range `[1, n]`.

A **XOR triplet** is defined as the XOR sum of three elements `nums[i] XOR nums[j] XOR nums[k]` where `i <= j <= k`.

Return the number of unique XOR triplet values from all possible triplets `(i, j, k)`.

---

### 💡 Intuition & Strategy

1. **Permutation Structure**:
   Since `nums` contains a complete permutation of all integers from `1` to `n`, every integer $x \in [1, n]$ is available for selection. Furthermore, picking $i = j = k$ allows us to yield any single value $x \oplus x \oplus x = x$.

2. **Base Cases ($n \le 2$)**:
   * **$n = 1$**: `nums = [1]`. The only valid triplet is `(0, 0, 0)`, giving $1 \oplus 1 \oplus 1 = 1$. Total unique values = **1**.
   * **$n = 2$**: `nums = [1, 2]`. The reachable values are $1$ and $2$. Total unique values = **2**.

3. **General Case ($n \ge 3$)**:
   * With three or more distinct values $1, \dots, n$, bitwise combinations through three-element XOR allow us to construct **every single integer** in the contiguous range $[0, 2^b - 1]$, where $b$ is the minimum number of bits required to represent $n$.
   * Consequently, the total count of distinct achievable XOR sums equals $2^b$ (i.e., the smallest power of 2 strictly greater than $n$).

4. **Bit Calculation**:
   * $b = 32 - \text{Integer.numberOfLeadingZeros}(n)$
   * The result is computed directly in $\mathcal{O}(1)$ time as `1 << b`.

---

### 💻 Java Solution

```java
/**
 * Problem: Unique XOR Triplets Count
 * Language: Java 17
 */
public class Solution {

    public int uniqueXorTriplets(int[] nums) {
        int n = nums.length;

        // Base cases for small arrays
        if (n <= 2) {
            return n;
        }

        // For n >= 3, the number of unique XOR values is 2^b, 
        // where b is the number of bits needed to represent n.
        int bitLength = 32 - Integer.numberOfLeadingZeros(n);
        return 1 << bitLength;
    }
}
```
### ⏱️ Complexity Analysis

| Section | Operation | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- |
| **Base Case Check** | Small Array Handling ($n \le 2$) | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ |
| **Bit Counting** | Leading Zeros Calculation (`LZCNT`/`BSR`) | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ |
| **Bit Shift** | Power of 2 Calculation ($1 \ll b$) | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ |
| **Overall** | **Total Complexity** | $\mathbf{\mathcal{O}(1)}$ | $\mathbf{\mathcal{O}(1)}$ |

> **Variables:**  
> - $n = |\text{nums}|$ (Length of the array `nums`)  
> - $b = \lceil \log_2(n + 1) \rceil$ (Number of bits required to represent $n$)
