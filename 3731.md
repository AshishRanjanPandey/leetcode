# 🚀 Find Missing Elements

### 📝 Problem Description

You are given an integer array `nums` consisting of unique integers.

Originally, `nums` contained every integer within a certain range. However, some integers might have gone missing from the array.

The smallest and largest integers of the original range are still present in `nums`.

Return a sorted list of all the missing integers in this range. If no integers are missing, return an empty list.

---

### 💡 Intuition & Strategy

1. **Range Identification**:
   * Find the minimum (`min`) and maximum (`max`) integers in `nums`.
   * The complete expected range is the contiguous sequence $[\text{min}, \text{max}]$.

2. **O(1) Existence Check**:
   * Insert all elements of `nums` into a hash set.
   * This allows us to check whether a specific integer is present in $O(1)$ time.

3. **In-Order Traversal**:
   * Iterate through all integers from `min` to `max` sequentially.
   * If an integer is not present in the set, append it to the result list.
   * Traversing from `min` to `max` guarantees that the resulting list is naturally sorted without requiring an explicit sorting step at the end.

---

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

/**
 * Language: Java 17
 * Time Complexity: O(N) where N = |nums|
 * Space Complexity: O(N) auxiliary space for lookup set
 */
public class Solution {

    public List<Integer> findMissingElements(int[] nums) {
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;
        Set<Integer> numSet = new HashSet<>();

        // Determine bounds and populate lookup set
        for (int num : nums) {
            if (num < min) min = num;
            if (num > max) max = num;
            numSet.add(num);
        }

        List<Integer> missing = new ArrayList<>();

        // Collect integers missing in the range [min, max]
        for (int i = min; i <= max; i++) {
            if (!numSet.contains(i)) {
                missing.add(i);
            }
        }

        return missing;
    }
}
```
---

### 📊 Complexity Analysis

| Parameter | Complexity | Details |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(N)$ | We perform a single pass over `nums` of length $N$ to find `min`/`max` and populate the `HashSet`. The range check loop runs $(M - m + 1)$ times, where $M$ is `max` and $m$ is `min`. Since $M - m \le 100$ per constraints, this iteration runs in bounded $\mathcal{O}(1)$ time. |
| **Space Complexity** | $\mathcal{O}(N)$ | The `HashSet` stores up to $N$ unique elements for $\mathcal{O}(1)$ membership checks. The output `List` requires auxiliary space proportional to the number of missing elements in the range. |
