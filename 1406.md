# 🚀 Stone Game III

### 📝 Problem Description

Alice and Bob continue their games with piles of stones. There are several stones arranged in a row, and each stone has an associated value which is an integer given in the array `stoneValue`.

Alice and Bob take turns, with Alice starting first. On each player's turn, that player can take **1, 2, or 3 stones** from the first remaining stones in the row.

The score of each player is the sum of the values of the stones taken. The score of each player is `0` initially. The objective of the game is to end with the highest score. The game continues until all the stones have been taken.

Assume Alice and Bob play optimally. Return `"Alice"` if Alice will win, `"Bob"` if Bob will win, or `"Tie"` if they will end the game with the same score.

---

### 💡 Intuition & Strategy

1. **Net Score Difference Advantage**:
   * Instead of tracking two independent running sums, we model $dp[i]$ as the **maximum relative score difference** (Current Player's Score − Opponent's Score) achievable starting from index $i$ to the end of the array.

2. **Minimax Recurrence**:
   * At index $i$, the active player can choose to take $X \in \{1, 2, 3\}$ stones.
   * If the player takes $X$ stones, they gain an immediate score equal to $\sum_{k=0}^{X-1} \text{stoneValue}[i + k]$, while the opponent gets to start from index $i + X$ with a relative advantage of $dp[i + X]$.
   * The relative score advantage gained by taking $X$ stones is:
     $$\text{Current Choice Score} - dp[i + X]$$
   * The active player maximizes this relative difference across all valid choices ($X = 1, 2, 3$):
     $$dp[i] = \max_{1 \le X \le 3} \left( \sum_{k=0}^{X-1} \text{stoneValue}[i + k] - dp[i + X] \right)$$

3. **Space Optimization**:
   * Notice that $dp[i]$ only depends on the next 3 positions: $dp[i+1]$, $dp[i+2]$, and $dp[i+3]$.
   * Thus, we can optimize the space complexity from $\mathcal{O}(N)$ down to $\mathcal{O}(1)$ using a rolling array of size 4.

---

### 💻 Java Solution

```java
/**
 * Problem: Stone Game III (LeetCode 1406)
 * Language: Java 17
 * Time Complexity: O(N) where N = |stoneValue|
 * Space Complexity: O(1) space-optimized DP
 */
public class Solution {

    public String stoneGameIII(int[] stoneValue) {
        int n = stoneValue.length;

        // dp array storing only the next 4 relevant states
        // dp[i % 4] stores the maximum relative score difference starting from index i
        int[] dp = new int[4];

        // Process backwards from the end of the array
        for (int i = n - 1; i >= 0; i--) {
            int maxDiff = Integer.MIN_VALUE;
            int currentTakeSum = 0;

            // Try taking 1, 2, or 3 stones
            for (int k = 0; k < 3 && i + k < n; k++) {
                currentTakeSum += stoneValue[i + k];
                
                // Relative score = current taken value - opponent's optimal advantage from remaining
                int nextStateIndex = (i + k + 1) % 4;
                maxDiff = Math.max(maxDiff, currentTakeSum - dp[nextStateIndex]);
            }

            dp[i % 4] = maxDiff;
        }

        // dp[0] represents (Alice's Score - Bob's Score) from the starting position
        int aliceNetAdvantage = dp[0];

        if (aliceNetAdvantage > 0) {
            return "Alice";
        } else if (aliceNetAdvantage < 0) {
            return "Bob";
        } else {
            return "Tie";
        }
    }
}
```
### ⏱️ Complexity Analysis

| Approach | Time Complexity | Space Complexity | Explanation |
| :--- | :--- | :--- | :--- |
| **Top-Down DP (Recursion + Memoization)** | $\mathcal{O}(N)$ | $\mathcal{O}(N)$ | Evaluates each state $i$ once with up to 3 transitions. Call stack and memo table take $\mathcal{O}(N)$ space. |
| **Bottom-Up DP (1D Array)** | $\mathcal{O}(N)$ | $\mathcal{O}(N)$ | Iterates through the array backwards from $N-1$ to $0$. The `dp` array requires $\mathcal{O}(N)$ auxiliary space. |
| **Space-Optimized DP (Rolling Array)** 🏆 | $\mathcal{O}(N)$ | $\mathcal{O}(1)$ | Uses a fixed-size array of length 4 since state $i$ only depends on $i+1$, $i+2$, and $i+3$. |
