# 🚀 Predict the Winner

### 📝 Problem Description

You are given an integer array `nums`. Two players are playing a game with this array: Player 1 and Player 2.

Player 1 and Player 2 take turns, with Player 1 starting first. Both players start the game with a score of `0`. At each turn, the player takes one of the numbers from either end of the array (i.e., `nums[0]` or `nums[nums.length - 1]`), which reduces the size of the array by 1. The player adds the chosen number to their score. The game ends when there are no more elements in the array.

Return `true` if Player 1 can win the game. If the scores of both players are equal, Player 1 is still the winner, and you should also return `true`. You may assume that both players are playing optimally.

---

### 💡 Intuition & Strategy

1. **Net Score Difference Advantage**:
   * Instead of maintaining separate scores for both players, we can formulate the problem as maximizing the **relative score difference** between the current player and the opponent.
   * If the current player picks a number, their advantage increases by that number's value, but then the opponent gets to play on the remaining sub-array. 

2. **Minimax Recurrence**:
   * If the current player takes `nums[i]`, the net score advantage gained is:
     $$\text{nums}[i] - \text{maxScoreDiff}(i + 1, j)$$
   * If the current player takes `nums[j]`, the net score advantage gained is:
     $$\text{nums}[j] - \text{maxScoreDiff}(i, j - 1)$$
   * The current player will optimally choose the move that maximizes this advantage:
     $$\text{dp}(i, j) = \max\Big(\text{nums}[i] - \text{dp}(i + 1, j),\; \text{nums}[j] - \text{dp}(i, j - 1)\Big)$$

3. **Optimization Trick**:
   * If the length of `nums` is **even**, Player 1 can always guarantee a win or tie. Player 1 can partition the array into odd and even indices and freely force the pick of whichever group has the larger sum.

### 💻 Java Solution

```java
/**
 * Problem: Predict the Winner (LeetCode 486)
 * Language: Java 17
 * Time Complexity: O(N^2) where N = |nums|
 * Space Complexity: O(N) using 1D DP optimization
 */
public class Solution {

    public boolean predictTheWinner(int[] nums) {
        int n = nums.length;
        
        // Even length optimization: Player 1 can always choose all even or all odd indexed elements
        if (n % 2 == 0) return true;

        // dp[j] stores the maximum score advantage for subarray nums[i...j]
        int[] dp = new int[n];

        // Base case: Subarrays of length 1
        for (int i = 0; i < n; i++) {
            dp[i] = nums[i];
        }

        // Build up solutions for longer subarrays
        for (int i = n - 2; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                int pickStart = nums[i] - dp[j];
                int pickEnd = nums[j] - dp[j - 1];
                dp[j] = Math.max(pickStart, pickEnd);
            }
        }

        // If net score advantage >= 0, Player 1 wins or ties
        return dp[n - 1] >= 0;
    }
}
```
### ⚡ Complexity Analysis

| Approach | Time Complexity | Space Complexity | Explanation |
| :--- | :--- | :--- | :--- |
| **Brute Force Recursion** | $\mathcal{O}(2^N)$ | $\mathcal{O}(N)$ | Explores all possible decision trees without caching results. Recursion stack depth is $N$. |
| **Top-Down DP (Memoization)** | $\mathcal{O}(N^2)$ | $\mathcal{O}(N^2)$ | Fills an $N \times N$ memo table of unique $(i, j)$ subproblems. Stack space is $\mathcal{O}(N)$. |
| **Bottom-Up 2D DP** | $\mathcal{O}(N^2)$ | $\mathcal{O}(N^2)$ | Iteratively fills an $N \times N$ matrix for all subarray lengths. |
| **Optimal 1D DP (Space-Optimized)** | $\mathcal{O}(N^2)$ | $\mathcal{O}(N)$ | Reuses a single 1D array of size $N$ since each state only depends on the current and previous row. |
