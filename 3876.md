# 🎯 LeetCode: Check if Array Can Be Made Uniform (Parity Match)

### 📝 Problem Description

You are given an array `nums1` of $n$ distinct integers.

You want to construct another array `nums2` of length $n$ such that the elements in `nums2` are either all odd or all even.

For each index $i$, you must choose exactly one of the following:
- `nums2[i] = nums1[i]`
- `nums2[i] = nums1[i] - nums1[j]`, for an index $j \neq i$, such that `nums1[i] - nums1[j] >= 1`

Return `true` if it is possible to construct such an array, otherwise, return `false`.

---

### 💡 Intuition & Strategy

1. **The Positive Difference Constraint**:
   The rule requires $nums1[i] - nums1[j] \ge 1$, which strictly implies:
   $$nums1[i] > nums1[j]$$
   You can only modify an element by subtracting a **strictly smaller** element from it.

2. **The Bottleneck of the Minimum Element**:
   - Let $m = \min(nums1)$.
   - Because $m$ is the absolute smallest value in the array, there exists no element $nums1[j]$ such that $nums1[j] < m$.
   - Thus, the minimum element cannot subtract anything. It **must** remain unchanged:
     $$nums2[\text{min\_idx}] = m$$
   - This single constraint dictates the target parity for the entire array: **all elements in `nums2` must match the parity of $m$**.

3. **Case 1: The Minimum Element $m$ is Odd**:
   - The target parity is **odd**.
   - If an element is already odd, keep it: $nums2[i] = nums1[i]$ ($\text{odd}$).
   - If an element $x$ is even, subtract the minimum element $m$:
     $$\text{even} - \text{odd} = \text{odd}$$
     Since $m$ is the minimum and all elements are distinct, $x > m$, so $x - m \ge 1$ always holds.
   - Every even number can successfully be transformed into an odd number.
   - **Result**: Always **`true`**.

4. **Case 2: The Minimum Element $m$ is Even**:
   - The target parity is **even**.
   - If all elements in `nums1` are already even, keep all elements as they are $\rightarrow$ **`true`**.
   - If there is at least one odd element, consider the **smallest odd element** in `nums1`, denoted $x_{\text{min\_odd}}$:
     - To convert an odd number to even, we must subtract a smaller odd number ($\text{odd} - \text{odd} = \text{even}$).
     - However, by definition, there is no odd number strictly smaller than $x_{\text{min\_odd}}$ in the array.
     - The only numbers smaller than $x_{\text{min\_odd}}$ are even numbers.
     - Subtracting an even number from an odd number yields $\text{odd} - \text{even} = \text{odd}$, which does not change the parity.
     - Therefore, $x_{\text{min\_odd}}$ can **never** be made even.
   - **Result**: **`false`** if any odd element exists.

5. **Decision Rule**:
   - If $\min(nums1)$ is odd $\rightarrow$ return `true`.
   - If $\min(nums1)$ is even $\rightarrow$ return `true` if and only if there are **no odd numbers** in `nums1`.

---

### ⚙️ Complexity Analysis

- **Time Complexity**: $O(n)$ — A single linear scan through `nums1` to find the minimum value and check for the presence of odd numbers.
- **Space Complexity**: $O(1)$ — Uses constant extra memory.

---

### 💻 Java Solution

```java
/**
 * Problem: Check if Array Can Be Made Uniform
 * Language: Java 17
 * Time Complexity: O(n)
 * Space Complexity: O(1)
 */
class Solution {

    public boolean uniformArray(int[] nums1) {
        int min = Integer.MAX_VALUE;
        boolean hasOdd = false;

        for (int num : nums1) {
            if (num < min) {
                min = num;
            }
            if ((num & 1) == 1) {
                hasOdd = true;
            }
        }

        // If the minimum element is odd, we can always make all elements odd.
        if ((min & 1) == 1) {
            return true;
        }

        // If the minimum element is even, we can only succeed if all elements are even.
        return !hasOdd;
    }
}
```
### ⚙️ Complexity Analysis

| Metric | Complexity | Reason |
| :--- | :---: | :--- |
| **Time Complexity** | $O(n)$ | Requires a single pass over the array of size $n$ to find the minimum value and check for odd elements. |
| **Space Complexity** | $O(1)$ | Operates in-place using only two scalar variables (`min` and `hasOdd`) without allocating extra memory. |
