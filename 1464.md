# 🚀 Maximum Product of Two Elements in an Array

### 📝 Problem Description

Given the array of integers `nums`, you will choose two different indices `i` and `j` of that array. Return the maximum value of `(nums[i]-1)*(nums[j]-1)`.

---

### 💡 Intuition & Strategy

1. **Understanding the Logic**:
   * Given the constraints $1 \le \text{nums}[i] \le 10^3$, all elements in the array are positive.
   * To maximize the product $(nums[i] - 1) \times (nums[j] - 1)$, we simply need to find the **two largest elements** in the array.
   * Decrementing both elements by $1$ and multiplying them will guarantee the maximum possible result.

2. **Single-Pass $O(N)$ Traversal**:
   * Instead of sorting the array in $O(N \log N)$ time, we can track the **two maximums** (`max1` and `max2`) in a single pass.

3. **Updating the Extremes**:
   For each element `n` in `nums`:
   * **For Maximums**:
     * If `n > max1`: `max2` becomes `max1`, and `max1` becomes `n`.
     * Else if `n > max2`: `max2` becomes `n`.

---

### 💻 Java Solution

```java
/**
 * Problem: Maximum Product of Two Elements in an Array
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 */
public class Solution {

    public int maxProduct(int[] nums) {
        int max1 = 0;
        int max2 = 0;

        for (int n : nums) {
            // Update top 2 maximums
            if (n > max1) {
                max2 = max1;
                max1 = n;
            } else if (n > max2) {
                max2 = n;
            }
        }

        return (max1 - 1) * (max2 - 1);
    }
}
```
---

### ⏱️ Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(N)$ | Single pass over the `nums` array of length $N$ to find top elements. |
| **Space Complexity** | $\mathcal{O}(1)$ | Uses a constant amount of extra memory (`max1` and `max2` variables). |
