# 🚀 Smallest Number With Digit Product Divisible by T

### 📝 Problem Description

You are given two integers `n` and `t`.

Return the smallest number greater than or equal to `n` such that the product of its digits is divisible by `t`.

---

### 💡 Intuition & Strategy

1. **Iterative Search**:
   * Start iterating from `n` upwards (`n`, `n + 1`, `n + 2`, ...).
   * For each candidate number, extract its digits and compute their product.

2. **Divisibility Check**:
   * Check if `digit_product % t == 0`.
   * Given `n <= 100` and `t <= 10`, a valid target is reached almost immediately.

3. **Termination**:
   * Return the candidate number as soon as the condition is satisfied to guarantee it is the smallest integer `>= n`.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(k * d) where k is the number of checked candidates and d is the number of digits in n
 * Space Complexity: O(1) auxiliary space
 */
public class Solution {

    public int smallestNumber(int n, int t) {
        while (true) {
            if (getDigitProduct(n) % t == 0) {
                return n;
            }
            n++;
        }
    }

    private int getDigitProduct(int num) {
        int product = 1;
        while (num > 0) {
            product *= (num % 10);
            num /= 10;
        }
        return product;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(k \cdot d)$ $\rightarrow \mathcal{O}(1)$ | Performs digit extraction for each candidate number. For $n \le 100$, digit length $d \le 3$ and candidate offset $k$ is extremely small, reducing to constant time. |
| **Space Complexity** | $\mathcal{O}(1)$ | Uses a fixed amount of extra memory for iteration and digit accumulation. |
