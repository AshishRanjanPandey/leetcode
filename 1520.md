# 🚀 LeetCode 1520 — Maximum Number of Non-Overlapping Substrings

### 📝 Problem Description
Given a string `s` of lowercase letters, find the maximum number of non-overlapping substrings that meet the condition: **a substring that contains a certain character $c$ must also contain all occurrences of $c$**. 

If there are multiple solutions with the same maximum number of substrings, return the one with the **minimum total length**.

---

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

/**
 * Problem: Maximum Number of Non-Overlapping Substrings (LeetCode 1520)
 * Language: Java 17
 */
class Solution {
    public List<String> maxNumOfSubstrings(String s) {
        int n = s.length();
        int[][] intervals = new int[26][2];
        
        // Step 1: Initialize intervals with maximum possible boundaries
        for (int i = 0; i < 26; i++) {
            intervals[i][0] = n;
        }
        
        // Find the first and last occurrence index of each character
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            intervals[c - 'a'][0] = Math.min(intervals[c - 'a'][0], i);
            intervals[c - 'a'][1] = Math.max(intervals[c - 'a'][1], i);
        }
        
        List<int[]> validIntervals = new ArrayList<>();
        
        // Step 2: Expand intervals to satisfy the condition that all occurrences 
        // of included characters are fully captured within the boundaries
        for (int i = 0; i < 26; i++) {
            if (intervals[i][0] == n) continue;
            
            int left = intervals[i][0];
            int right = intervals[i][1];
            int minLeft = left;
            int maxRight = right;
            
            boolean isValid = true;
            for (int j = minLeft; j <= maxRight; j++) {
                int charIdx = s.charAt(j) - 'a';
                // If a character appears earlier than our current left bound,
                // it implies this interval leaks outside and is invalid.
                if (intervals[charIdx][0] < left) {
                    isValid = false;
                    break;
                }
                minLeft = Math.min(minLeft, intervals[charIdx][0]);
                maxRight = Math.max(maxRight, intervals[charIdx][1]);
            }
            
            if (isValid) {
                validIntervals.add(new int[]{minLeft, maxRight});
            }
        }
        
        // Step 3: Sort valid intervals by their end points (ascending), then start points
        Collections.sort(validIntervals, (a, b) -> {
            if (a[1] != b[1]) {
                return Integer.compare(a[1], b[1]);
            }
            return Integer.compare(a[0], b[0]);
        });
        
        // Step 4: Greedy interval scheduling for non-overlapping selection
        List<String> result = new ArrayList<>();
        int prevEnd = -1;
        
        for (int[] interval : validIntervals) {
            if (interval[0] > prevEnd) {
                result.add(s.substring(interval[0], interval[1] + 1));
                prevEnd = interval[1];
            }
        }
        
        return result;
    }
}
```
### 📊 Complexity Analysis

| Complexity | Time | Space | Reason |
| :--- | :--- | :--- | :--- |
| **Worst Case** | $O(N)$ | $O(1)$ | Finding bounds takes $O(N)$ time, and expanding character intervals takes at most $O(26 \times N)$ operations. The auxiliary space is bounded by the alphabet size (26 characters). |
