# 🎯 LeetCode 2904: Shortest Beautiful Substring

### 📝 Problem Description

You are given a binary string `s` and a positive integer `k`.

A substring of `s` is **beautiful** if the number of `'1'`s in it is exactly `k`.

Let `len` be the length of the shortest beautiful substring.

Return the **lexicographically smallest** beautiful substring of string `s` with length equal to `len`. If `s` does not contain a beautiful substring, return an empty string `""`.

---

### 💡 Intuition & Strategy

1. **Sliding Window / Two-Pointer Approach**:
   * Expand a sliding window using the `right` pointer while counting the number of `'1'`s encountered.
   * When the count reaches `k`, shrink the window from the left to remove leading zeros, since any prefix of `'0'`s only increases the substring's length without contributing to the count of `'1'`s.

2. **Candidate Selection & Lexicographical Comparison**:
   * Once a valid window containing exactly `k` ones is identified:
     * Extract the substring `s.substring(left, right + 1)`.
     * If this substring is shorter than the current `result` (or if `result` is empty), update `result`.
     * If the length equals the current shortest length, compare them lexicographically using `compareTo()` and choose the smaller one.
   * Advance the `left` pointer past the first `'1'` in the current window to continue searching for subsequent candidates.

3. **Complexity**:
   * **Time Complexity**: $O(n^2)$ — where $n$ is the length of `s`. The two pointers process each character at most twice ($O(n)$), and substring extraction/string comparison takes up to $O(n)$ time.
   * **Space Complexity**: $O(n)$ — required to store the candidate substrings and the resulting string.

---

### 💻 Java Solution

```java
/**
 * Problem: 2904. Shortest Beautiful Substring
 * Language: Java 17
 * Time Complexity: O(n^2)
 * Space Complexity: O(n)
 */
class Solution {

    public String shortestBeautifulSubstring(String s, int k) {
        int n = s.length();
        int left = 0;
        int count = 0;
        String result = "";

        for (int right = 0; right < n; right++) {
            if (s.charAt(right) == '1') {
                count++;
            }

            // When window contains k '1's, shrink and evaluate
            while (count == k) {
                // Trim leading zeros to minimize length
                while (left <= right && s.charAt(left) == '0') {
                    left++;
                }

                String current = s.substring(left, right + 1);

                // Update result if current is shorter or lexicographically smaller
                if (result.isEmpty() || current.length() < result.length()) {
                    result = current;
                } else if (current.length() == result.length() && current.compareTo(result) < 0) {
                    result = current;
                }

                // Move left pointer past the first '1' to explore next window
                if (s.charAt(left) == '1') {
                    count--;
                }
                left++;
            }
        }

        return result;
    }
}
```
### 📊 Complexity Analysis

| Operation / Aspect | Complexity | Details |
| :--- | :--- | :--- |
| **Two-Pointer Traversal** | $\mathcal{O}(n)$ | Both `left` and `right` pointers traverse the string at most once. |
| **Substring & Comparison** | $\mathcal{O}(n)$ | String slicing and lexicographical comparison take linear time per match. |
| **Total Time Complexity** | $\mathcal{O}(n^2)$ | In the worst case, $O(n)$ valid windows trigger $O(n)$ comparisons. |
| **Total Space Complexity** | $\mathcal{O}(n)$ | Stores candidate slices and the shortest result string in memory. |
