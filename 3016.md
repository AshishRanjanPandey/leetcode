# 🚀 Minimum Number of Key Pushes to Type Word II

### 📝 Problem Description

You are given a string `word` containing lowercase English letters.

Telephone keypads have keys mapped with distinct collections of lowercase English letters, which can be used to form words by pushing them. Keys numbered `2` to `9` can be remapped to any number of distinct letters, but each letter must be mapped to exactly one key.

Return the **minimum number of pushes** needed to type `word` after remapping the keys.

---

### 💡 Intuition & Strategy

1. **Greedy Frequency Allocation**:
   * Unlike Part I where characters are distinct, characters in `word` can repeat.
   * To minimize overall key presses, characters with the **highest frequencies** must be placed in positions requiring fewer presses (1 push), while lower-frequency characters can take positions requiring more presses (2, 3, or 4 pushes).

2. **Sequential Slot Distribution**:
   * We have **8 available keys** on the telephone keypad (keys `2` through `9`).
   * **1st Push Position**: Top 8 most frequent characters (cost: 1 push per occurrence).
   * **2nd Push Position**: Next 8 most frequent characters (9th to 16th) (cost: 2 pushes per occurrence).
   * **3rd Push Position**: Next 8 most frequent characters (17th to 24th) (cost: 3 pushes per occurrence).
   * **4th Push Position**: Remaining 2 characters (25th and 26th) (cost: 4 pushes per occurrence).

3. **Algorithm**:
   * Count frequency of each letter ($a$-$z$).
   * Sort frequencies in descending order.
   * For the $i$-th letter (0-indexed) in sorted order, the cost per occurrence is $\left\lfloor \frac{i}{8} \right\rfloor + 1$.

---

### 💻 Java Solution

```java
import java.util.Arrays;

/**
 * Problem: Minimum Number of Key Pushes to Type Word II
 * Language: Java 17
 * Time Complexity: O(N) where N = |word|
 * Space Complexity: O(1)
 */
public class Solution {

    public int minimumPushes(String word) {
        // Step 1: Count frequency of each character
        int[] freq = new int[26];
        for (char c : word.toCharArray()) {
            freq[c - 'a']++;
        }

        // Step 2: Sort frequencies in ascending order
        Arrays.sort(freq);

        int totalPushes = 0;

        // Step 3: Map highest frequencies to positions with fewest pushes
        for (int i = 0; i < 26; i++) {
            int count = freq[26 - 1 - i]; // Process in descending order
            if (count == 0) break;         // Stop early if remaining frequencies are zero

            int pushesPerChar = (i / 8) + 1;
            totalPushes += count * pushesPerChar;
        }

        return totalPushes;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :---: | :--- |
| **Time Complexity** | $\mathcal{O}(N)$ | Counting frequencies takes $\mathcal{O}(N)$ where $N = \text{length of } \texttt{word}$. Sorting the $26$-element array takes $\mathcal{O}(26 \log 26) = \mathcal{O}(1)$ time. |
| **Space Complexity** | $\mathcal{O}(1)$ | Uses a fixed-size array of $26$ integers to store frequencies regardless of input size. |
| **Auxiliary Space** | $\mathcal{O}(1)$ | No additional dynamic memory allocation beyond the fixed array. |
