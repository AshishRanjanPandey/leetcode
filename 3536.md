# 🚀 Maximum Product of Two Digits

### 📝 Problem Description

You are given a positive integer `n`.

Return the **maximum product** of any two digits in `n`.

> **Note:** You may use the same digit twice if it appears more than once in `n`.

---

### 💡 Intuition & Strategy

1. **Greedy Selection**:
   To maximize the product of two numbers chosen from a fixed set of non-negative digits, we simply need to pick the **largest digit** and the **second-largest digit**.

2. **Single-Pass Digit Extraction**:
   * Instead of converting `n` to a string or allocating additional space, we can process digits from right to left using arithmetic operations (`n % 10` and `n /= 10`).
   * We maintain two running tracking variables: `max1` (the highest digit seen so far) and `max2` (the second-highest digit seen so far).

3. **Updating the Maxima**:
   For each extracted digit:
   * If `digit > max1`: The previous `max1` shifts to become `max2`, and `max1` takes the value of `digit`.
   * Else if `digit > max2`: `max2` is updated to `digit`.

4. **Edge Cases & Repetition**:
   Because the problem explicitly allows picking the same digit twice if it appears multiple times (e.g., `n = 22`), if a number has two identical highest digits (like two `9`s), `max1` and `max2` will both equal `9`, yielding $9 \times 9 = 81$.

---

### 💻 Java Solution

```java
/**
 * Problem: Maximum Product of Two Digits
 * Language: Java 17
 */
public class Solution {

    public int maxProduct(int n) {
        int max1 = 0;
        int max2 = 0;

        while (n > 0) {
            int digit = n % 10;

            if (digit > max1) {
                max2 = max1;
                max1 = digit;
            } else if (digit > max2) {
                max2 = digit;
            }

            n /= 10;
        }

        return max1 * max2;
    }
}
```
### 📊 Complexity Analysis

| Type | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(\log_{10} n)$ | The loop executes once per digit of `n`. Since $n \le 10^9$, there are at most 10 digits, making it virtually constant time $\mathcal{O}(1)$. |
| **Space Complexity** | $\mathcal{O}(1)$ | Uses a constant amount of memory with only two integer tracking variables (`max1`, `max2`). |
