# 🚀 Lexicographically Smallest Palindromic Permutation

### 📝 Problem Description

Given a palindromic string `s`, return the **lexicographically smallest palindromic permutation** of `s`.

---

### 💡 Intuition & Strategy

1. **Understanding the Logic**:
   * Since `s` is already guaranteed to be a valid palindrome, at most **one character** can have an odd frequency, while all other characters have even frequencies.
   * A palindrome is symmetric, so it is completely defined by its **left half** and its **middle character** (if the length is odd).
   * To minimize the string lexicographically, we must construct the **left half** with the smallest possible characters placed as early as possible.

2. **Frequency Counting & Sorting**:
   * Count the frequency of each character (`'a'` through `'z'`) in a fixed-size array of length 26.
   * Iterate from `'a'` to `'z'`. For each character:
     * Add half of its count (`count[i] / 2`) to the `leftHalf`. Since we process characters in alphabetical order, this guarantees the left half is lexicographically smallest.
     * If a character has an odd frequency, record it as the `middleChar`.

3. **Constructing the Result**:
   * Mirror `leftHalf` to form `rightHalf`.
   * Combine them as: `leftHalf` + `middleChar` (if present) + `rightHalf`.

---

### 💻 Java Solution

```java
/**
 * Problem: Lexicographically Smallest Palindromic Permutation
 * Language: Java 17
 * Time Complexity: O(N)
 * Space Complexity: O(N)
 */
public class Solution {

    public String smallestPalindrome(String s) {
        int[] count = new int[26];
        
        // Step 1: Count character frequencies
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
        }
        
        StringBuilder leftHalf = new StringBuilder();
        char middleChar = 0;
        
        // Step 2: Build the lexicographically smallest left half
        for (int i = 0; i < 26; i++) {
            if (count[i] > 0) {
                char ch = (char) ('a' + i);
                
                // Track middle character if frequency is odd
                if (count[i] % 2 != 0) {
                    middleChar = ch;
                }
                
                // Append half of the frequency to leftHalf
                for (int j = 0; j < count[i] / 2; j++) {
                    leftHalf.append(ch);
                }
            }
        }
        
        // Step 3: Mirror the left half to create the right half
        StringBuilder rightHalf = new StringBuilder(leftHalf).reverse();
        
        // Step 4: Assemble left half + middle character + right half
        if (middleChar != 0) {
            leftHalf.append(middleChar);
        }
        
        return leftHalf.append(rightHalf).toString();
    }
}
```
### ⏱️ Complexity Analysis

| Type | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $O(N)$ | Counting frequencies takes $O(N)$ time. Building the left and right halves iterates over a fixed array of size 26 and performs string operations linear to $N$. |
| **Space Complexity** | $O(N)$ | Uses an $O(1)$ array of size 26 for character counts, and $O(N)$ auxiliary space for `StringBuilder` instances to construct the final output. |
