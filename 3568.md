# 🎯 LeetCode: Minimum Moves to Collect All Litter

### 📝 Problem Description

You are given an $m \times n$ grid `classroom` where a student volunteer is tasked with cleaning up litter scattered around the room. Each cell in the grid is one of the following:

- `'S'`: Starting position of the student
- `'L'`: Litter that must be collected (once collected, the cell becomes empty)
- `'R'`: Reset area that restores the student's energy to full capacity, regardless of their current energy level (can be used multiple times)
- `'X'`: Obstacle the student cannot pass through
- `'.'`: Empty space

You are also given an integer `energy`, representing the student's maximum energy capacity. The student starts with this energy from the starting position `'S'`.

Each move to an adjacent cell (up, down, left, or right) costs $1$ unit of energy. If the energy reaches $0$, the student can only continue if they are on a reset area `'R'`, which resets the energy to its maximum capacity `energy`.

Return the **minimum number of moves** required to collect all litter items, or `-1` if it is impossible.

---

### 💡 Intuition & Strategy

1. **State Space Representation with Bitmasking**:
   - There are at most $K \le 10$ litter cells (`'L'`). We can assign each litter cell a unique bit index from $0$ to $K - 1$.
   - A bitmask `mask` of length $K$ represents which litter items have been collected so far ($0 \le \text{mask} < 2^K$).
   - A search state is defined as `(r, c, mask, remaining_energy)`.

2. **Breadth-First Search (BFS) & State Pruning**:
   - Since all edge weights represent $1$ move, standard BFS guarantees finding the minimum number of moves.
   - For any configuration `(r, c, mask)`, arriving with **more remaining energy** strictly dominates arriving with equal or lesser energy.
   - Maintain a 3D memoization table `maxEnergy[r][c][mask]` initialized to $-1$.
   - If we reach a state `(r, c, mask)` with `energy <= maxEnergy[r][c][mask]`, prune the branch immediately.

3. **Transitions & Energy Constraints**:
   - From cell `(r, c)`, move to an adjacent non-obstacle cell `(nr, nc)`.
   - Energy decreases by $1$: `nextEnergy = energy - 1`.
   - If the cell is a litter cell `'L'`, update `nextMask = mask | (1 << litterId)`.
   - If the cell is a reset cell `'R'`, recharge energy: `nextEnergy = maxCapacity`.
   - If `nextMask == (1 << K) - 1`, all litter is collected; return the move count immediately.
   - A transition is valid only if the move was possible before running out of energy (i.e. current energy $> 0$).

4. **Complexity**:
   - **Time Complexity**: $O(m \cdot n \cdot 2^K)$ — where $m, n \le 20$ and $K \le 10$. Total reachable states are at most $20 \times 20 \times 1024 \approx 4.1 \times 10^5$.
   - **Space Complexity**: $O(m \cdot n \cdot 2^K)$ — to store the BFS queue and the 3D memoization table `maxEnergy`.

### 💻 Java Solution

```java
/**
 * Problem: Minimum Moves to Collect All Litter
 * Language: Java 17
 * Time Complexity: O(m * n * 2^K)
 * Space Complexity: O(m * n * 2^K)
 */
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

class Solution {

    public int minMoves(String[] classroom, int energy) {
        int m = classroom.length;
        int n = classroom[0].length();

        int startR = -1;
        int startC = -1;
        int litterCount = 0;
        int[][] litterId = new int[m][n];

        for (int[] row : litterId) {
            Arrays.fill(row, -1);
        }

        // 1. Identify start position and index all litter locations
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                char ch = classroom[r].charAt(c);
                if (ch == 'S') {
                    startR = r;
                    startC = c;
                } else if (ch == 'L') {
                    litterId[r][c] = litterCount++;
                }
            }
        }

        // Base case: No litter to collect
        if (litterCount == 0) {
            return 0;
        }

        int targetMask = (1 << litterCount) - 1;

        // maxEnergy[r][c][mask] stores the maximum remaining energy seen for state (r, c, mask)
        int[][][] maxEnergy = new int[m][n][1 << litterCount];
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                Arrays.fill(maxEnergy[r][c], -1);
            }
        }

        // Queue elements: {r, c, mask, currentEnergy, moves}
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{startR, startC, 0, energy, 0});
        maxEnergy[startR][startC][0] = energy;

        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        // 2. Perform Breadth-First Search
        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int r = curr[0];
            int c = curr[1];
            int mask = curr[2];
            int curEnergy = curr[3];
            int moves = curr[4];

            if (mask == targetMask) {
                return moves;
            }

            // Cannot move forward if energy is completely exhausted on a non-reset cell
            if (curEnergy == 0) {
                continue;
            }

            for (int[] dir : directions) {
                int nr = r + dir[0];
                int nc = c + dir[1];

                // Bounds and obstacle checking
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || classroom[nr].charAt(nc) == 'X') {
                    continue;
                }

                char cellType = classroom[nr].charAt(nc);
                int nextEnergy = curEnergy - 1;
                int nextMask = mask;

                // Collect litter if available at destination
                if (cellType == 'L' && litterId[nr][nc] != -1) {
                    nextMask |= (1 << litterId[nr][nc]);
                }

                // Reset energy at 'R' cell
                if (cellType == 'R') {
                    nextEnergy = energy;
                }

                // Push only if we reach this state with strictly better remaining energy
                if (nextEnergy > maxEnergy[nr][nc][nextMask]) {
                    maxEnergy[nr][nc][nextMask] = nextEnergy;
                    queue.offer(new int[]{nr, nc, nextMask, nextEnergy, moves + 1});
                }
            }
        }

        return -1;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Details |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(m \cdot n \cdot 2^K)$ | There are at most $m \times n \times 2^K$ unique states $(r, c, \text{mask})$. Each state transitions to up to $4$ adjacent neighbors in $\mathcal{O}(1)$ time, taking $\approx 20 \times 20 \times 1024 \approx 4.1 \times 10^5$ operations in the worst case. |
| **Space Complexity** | $\mathcal{O}(m \cdot n \cdot 2^K)$ | Required to maintain the 3D memoization array `maxEnergy[m][n][1 << K]` and the BFS queue storing at most one entry per state. |
| **Bitmask Overhead** | $\mathcal{O}(K)$ | Space and operation cost to map and index the positions of the litter items where $K \le 10$. |
