# 🎯 LeetCode: Maximum Score of Non-overlapping Intervals

### 📝 Problem Description

You are given a 2D integer array `intervals`, where `intervals[i] = [l_i, r_i, weight_i]`. Interval `i` starts at position $l_i$ and ends at $r_i$, and has a weight of $weight_i$.

You can choose **up to 4 non-overlapping intervals**. The score of the chosen intervals is defined as the total sum of their weights.

Return the lexicographically smallest array of at most 4 indices from `intervals` with maximum score, representing your choice of non-overlapping intervals.

Two intervals are said to be non-overlapping if they do not share any points. In particular, intervals sharing a left or right boundary are considered overlapping (i.e., if interval $A$ ends at $r_A$ and interval $B$ starts at $l_B$, they are non-overlapping if and only if $r_A < l_B$).

**Example 1:**
- **Input:** `intervals = [[1,3,2],[4,5,2],[1,5,5],[6,9,3],[6,7,1],[8,9,1]]`
- **Output:** `[2,3]`
- **Explanation:**
  - Choosing interval 2 ($[1, 5, 5]$) and interval 3 ($[6, 9, 3]$) gives a total weight of $5 + 3 = 8$.
  - These two intervals do not overlap ($5 < 6$).
  - No other valid combination of at most 4 intervals yields a strictly higher score.

**Example 2:**
- **Input:** `intervals = [[5,8,1],[6,7,7],[4,7,3],[9,10,6],[7,8,2],[11,14,3],[3,5,5]]`
- **Output:** `[1,3,5,6]`
- **Explanation:**
  - Choosing intervals 1 ($[6, 7, 7]$), 3 ($[9, 10, 6]$), 5 ($[11, 14, 3]$), and 6 ($[3, 5, 5]$) gives a total weight of $7 + 6 + 3 + 5 = 21$.
  - All chosen intervals are mutually disjoint: $[3, 5]$, $[6, 7]$, $[9, 10]$, and $[11, 14]$.

**Constraints:**
- $1 \le \text{intervals.length} \le 5 \times 10^4$
- $\text{intervals}[i].\text{length} == 3$
- $1 \le l_i \le r_i \le 10^9$
- $1 \le weight_i \le 10^9$

---

### 💡 Intuition & Strategy

1. **Interval Scheduling with Weights ($k \le 4$)**:
   - This problem is an extension of the classic Weighted Interval Scheduling problem, bounded by a maximum cardinality constraint ($k \in \{1, 2, 3, 4\}$).
   - Because weights are strictly positive, any optimal subset can be evaluated using Dynamic Programming.

2. **Sorting & Binary Search Transitions**:
   - Augment each interval with its original index: `(l, r, weight, id)`.
   - Sort all intervals by their right boundary $r$ ascending.
   - For interval $i$ ending at $r_i$ and starting at $l_i$, find the rightmost preceding interval $p < i$ such that:
     $$r_p < l_i$$
   - This predecessor index $p$ can be located in $O(\log N)$ time using binary search.

3. **DP State Representation & Lexicographical Tie-Breaking**:
   - Let `dp[i][k]` denote the optimal state considering a prefix of the first $i$ sorted intervals, choosing exactly $k$ intervals ($1 \le k \le 4$).
   - Each state stores:
     - `weight`: The total cumulative weight.
     - `indices`: A sorted list of the original indices selected.
   - Transitions:
     - **Skip interval $i$**: Inherit `dp[i - 1][k]`.
     - **Take interval $i$**: Form a new state from `dp[p][k - 1]` with weight $\text{weight} + weight_i$ and append/insert $id_i$ maintaining sorted order.
   - **Comparison Rule**: State $A$ is better than State $B$ if:
     - $A.\text{weight} > B.\text{weight}$, OR
     - $A.\text{weight} == B.\text{weight}$ and $A.\text{indices}$ is lexicographically smaller than $B.\text{indices}$.

4. **Complexity**:
   - **Time Complexity**: $O(N \log N)$ — Sorting takes $O(N \log N)$. For each of the $N$ intervals, binary search takes $O(\log N)$ and updating up to 4 states takes $O(1)$ operations with lists of length $\le 4$.
   - **Space Complexity**: $O(N)$ — Dynamic programming table storing states of size up to 4 for each prefix.

### 💻 Java Solution

```java
import java.util.*;

/**
 * Problem: Maximum Score of Non-overlapping Intervals
 * Language: Java 17 / 21
 * Time Complexity: O(N log N)
 * Space Complexity: O(N)
 */
class Solution {

    static class Interval {
        int l, r, weight, id;

        Interval(int l, int r, int weight, int id) {
            this.l = l;
            this.r = r;
            this.weight = weight;
            this.id = id;
        }
    }

    static class State {
        long weight;
        List<Integer> indices;

        State(long weight, List<Integer> indices) {
            this.weight = weight;
            this.indices = indices;
        }

        /**
         * Compares this state against another state.
         * Priority: higher weight -> lexicographically smaller index list.
         */
        boolean isBetterThan(State other) {
            if (other == null) return true;
            if (this.weight != other.weight) {
                return this.weight > other.weight;
            }
            int len = Math.min(this.indices.size(), other.indices.size());
            for (int i = 0; i < len; i++) {
                int a = this.indices.get(i);
                int b = other.indices.get(i);
                if (a != b) {
                    return a < b;
                }
            }
            return this.indices.size() < other.indices.size();
        }
    }

    public int[] maximumWeight(List<List<Integer>> intervals) {
        int n = intervals.size();
        Interval[] arr = new Interval[n];
        for (int i = 0; i < n; i++) {
            List<Integer> item = intervals.get(i);
            arr[i] = new Interval(item.get(0), item.get(1), item.get(2), i);
        }

        // Sort by end boundary r ascending
        Arrays.sort(arr, (a, b) -> Integer.compare(a.r, b.r));

        // dp[i][k]: best state choosing k intervals from prefix arr[0..i-1]
        State[][] dp = new State[n + 1][5];
        for (int i = 0; i <= n; i++) {
            for (int k = 0; k <= 4; k++) {
                dp[i][k] = new State(0, new ArrayList<>());
            }
        }

        for (int i = 1; i <= n; i++) {
            Interval cur = arr[i - 1];

            // Binary search for the rightmost interval ending strictly before cur.l
            int low = 0, high = i - 2, prevIdx = -1;
            while (low <= high) {
                int mid = low + (high - low) / 2;
                if (arr[mid].r < cur.l) {
                    prevIdx = mid;
                    low = mid + 1;
                } else {
                    high = mid - 1;
                }
            }

            int p = prevIdx + 1; // Convert to 1-based DP index

            for (int k = 1; k <= 4; k++) {
                // Option 1: Exclude cur
                State best = dp[i - 1][k];

                // Option 2: Include cur
                State prevState = dp[p][k - 1];
                long newWeight = prevState.weight + cur.weight;
                List<Integer> newIndices = new ArrayList<>(prevState.indices);

                // Insert cur.id while keeping the index list sorted
                int insertPos = Collections.binarySearch(newIndices, cur.id);
                if (insertPos < 0) {
                    insertPos = -(insertPos + 1);
                }
                newIndices.add(insertPos, cur.id);

                State take = new State(newWeight, newIndices);
                if (take.isBetterThan(best)) {
                    best = take;
                }

                dp[i][k] = best;
            }
        }

        // Determine optimal result across choices of 1, 2, 3, or 4 intervals
        State optimal = dp[n][1];
        for (int k = 2; k <= 4; k++) {
            if (dp[n][k].isBetterThan(optimal)) {
                optimal = dp[n][k];
            }
        }

        int[] result = new int[optimal.indices.size()];
        for (int i = 0; i < optimal.indices.size(); i++) {
            result[i] = optimal.indices.get(i);
        }
        return result;
    }
}
