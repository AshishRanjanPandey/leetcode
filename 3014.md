# 🚀 Minimum Number of Key Pushes to Type Word I

### 📝 Problem Description

You are given a string `word` containing **distinct** lowercase English letters.

Telephone keypads have keys mapped with distinct collections of lowercase English letters, which can be used to form words by pushing them. Keys numbered `2` to `9` can be remapped to any number of distinct letters, but each letter must be mapped to exactly one key.

Return the **minimum number of pushes** needed to type `word` after remapping the keys.

---

### 💡 Intuition & Strategy

1. **Greedy Allocation Strategy**:
   * We have **8 available keys** on the telephone keypad (keys `2` through `9`).
   * To minimize the total number of key presses, we should place as many distinct characters as possible into the **1st position** of each key before using the 2nd, 3rd, or 4th positions.

2. **Sequential Slot Distribution**:
   * **1st Push Position**: The first 8 distinct characters go to the 1st slot across keys `2`–`9` (cost: 1 push each).
   * **2nd Push Position**: The next 8 characters (9th through 16th) go to the 2nd slot (cost: 2 pushes each).
   * **3rd Push Position**: The next 8 characters (17th through 24th) go to the 3rd slot (cost: 3 pushes each).
   * **4th Push Position**: The remaining characters (25th and 26th) go to the 4th slot (cost: 4 pushes each).

3. **Mathematical Mapping**:
   * For a character at 0-based index `i` in `word`, the required number of pushes is directly computed as:
     $$\text{Pushes} = \left\lfloor \frac{i}{8} \right\rfloor + 1$$

---

### 💻 Java Solution

```java
/**
 * Problem: Minimum Number of Key Pushes to Type Word I
 * Language: Java 17
 * Time Complexity: O(|word|) -> O(1) since |word| <= 26
 * Space Complexity: O(1)
 */
public class Solution {

    public int minimumPushes(String word) {
        int n = word.length();
        int totalPushes = 0;

        // Iterate through each character position in the distinct string
        for (int i = 0; i < n; i++) {
            // (i / 8) + 1 yields:
            // Indices 0-7   -> 1 push
            // Indices 8-15  -> 2 pushes
            // Indices 16-23 -> 3 pushes
            // Indices 24-25 -> 4 pushes
            totalPushes += (i / 8) + 1;
        }

        return totalPushes;
    }
}
```
### 📊 Complexity Analysis

| Measure | Complexity | Constraints / Upper Bound | Explanation |
| :--- | :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(1)$ | $|word| \le 26$ | The string contains distinct characters, so its length is at most 26. The loop iterates at most 26 times, operating in constant time. |
| **Space Complexity** | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ auxiliary memory | Uses only a couple of primitive integer variables (`n`, `totalPushes`, `i`) without additional data structures. |
