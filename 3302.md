# 🚀 Find the Lexicographically Smallest Valid Sequence

### 📝 Problem Description

You are given two strings `word1` and `word2`.

A string $x$ is called **almost equal** to $y$ if you can change at most one character in $x$ to make it identical to $y$.

A sequence of indices `seq` is called **valid** if:
* The indices are sorted in ascending order.
* Concatenating the characters at these indices in `word1` in the same order results in a string that is almost equal to `word2`.

Return an array of size `word2.length` representing the **lexicographically smallest valid sequence** of indices. If no such sequence of indices exists, return an empty array.

---

### 💡 Intuition & Strategy

1. **Suffix Precomputation (`right` Array)**:
   * Maintain a `right` array where `right[i]` represents the **maximum index in `word1`** from which the suffix `word2[i...m-1]` can be matched **exactly** ($0$ mismatches).
   * Populated backwards from `m - 1` down to `0`. If `right[i + 1]` is known, we find the largest index $p < \text{right}[i + 1]$ such that `word1[p] == word2[i]`.

2. **Greedy Forward Selection**:
   * Iterate through `word2` from index $0$ to $m - 1$. For each position $i$, greedily pick the **smallest index $j > \text{prevIdx}$ in `word1`**.
   * **Exact Match (`word1[j] == word2[i]`)**:
     Valid if either we haven't used our allowed $1$ mismatch yet (so the mismatch can be saved for the remaining suffix), OR the remaining suffix `word2[i + 1...m - 1]` can be matched with $0$ mismatches (`right[i + 1] > j`).
   * **Mismatch Choice (`word1[j] != word2[i]`)**:
     Valid ONLY if we **have not used a mismatch yet** AND the remaining suffix `word2[i + 1...m - 1]` can be matched with $0$ mismatches (`right[i + 1] > j`).

3. **Termination**:
   * The first valid index $j$ encountered during the forward scan guarantees the lexicographically smallest choice for `result[i]`. If no index works for some character, return an empty array `[]`.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(n + m) where n = word1.length() and m = word2.length()
 * Space Complexity: O(m) auxiliary space for the right array and result
 */
public class Solution {

    public int[] validSequence(String word1, String word2) {
        int n = word1.length();
        int m = word2.length();

        // right[i] stores the maximum index in word1 such that suffix word2[i...m-1] 
        // can be matched exactly (0 mismatches) starting at or after right[i].
        int[] right = new int[m + 1];
        right[m] = n;

        int p = n - 1;
        for (int i = m - 1; i >= 0; i--) {
            while (p >= 0 && word1.charAt(p) != word2.charAt(i)) {
                p--;
            }
            right[i] = p;
            if (p >= 0) {
                p--; // Preceding match must strictly precede the current match index
            }
        }

        int[] result = new int[m];
        int prevIdx = -1;
        boolean mismatchUsed = false;

        for (int i = 0; i < m; i++) {
            boolean found = false;

            // Greedily pick the smallest possible index j in word1 > prevIdx
            for (int j = prevIdx + 1; j < n; j++) {
                boolean isMatch = (word1.charAt(j) == word2.charAt(i));

                if (isMatch) {
                    // Option A: Exact match at j
                    // Valid if remaining suffix can be matched with 0 mismatches OR mismatch is still available
                    if (right[i + 1] > j || !mismatchUsed) {
                        result[i] = j;
                        prevIdx = j;
                        found = true;
                        break;
                    }
                } else {
                    // Option B: Use our 1 allowed mismatch at j
                    // Valid only if mismatch hasn't been used AND remaining suffix matches with 0 mismatches
                    if (!mismatchUsed && right[i + 1] > j) {
                        result[i] = j;
                        prevIdx = j;
                        mismatchUsed = true;
                        found = true;
                        break;
                    }
                }
            }

            if (!found) {
                return new int[0]; // Impossible to form a valid sequence
            }
        }

        return result;
    }
}
```

### ⏱️ Complexity Analysis

| Resource | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(n + m)$ | Precomputing the `right` array takes $\mathcal{O}(n + m)$ time. The forward greedy scan processes each character in $word1$ at most a constant number of times. |
| **Space Complexity** | $\mathcal{O}(m)$ | Requires $\mathcal{O}(m)$ auxiliary space for the `right` array and the `result` output array. |

> Where $n = \text{word1.length()}$ and $m = \text{word2.length()}$.
