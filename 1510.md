# 🚀 Stone Game IV

### 📝 Problem Description

Alice and Bob take turns playing a game, with Alice starting first.

Initially, there are `n` stones in a pile. On each player's turn, that player makes a move consisting of removing any non-zero square number of stones from the pile.

Also, if a player cannot make a move, he/she loses the game.

Given a positive integer `n`, return `true` if and only if Alice wins the game assuming both players play optimally, otherwise return `false`.

---

### 💡 Intuition & Strategy

1. **Game Theory & Dynamic Programming Definition**:
   * Let `dp[i]` be a boolean value representing whether the player whose turn it is can guarantee a **win** starting with `i` stones.
   * **Base Case**: `dp[0] = false` because a player facing $0$ stones has no valid square numbers to subtract and immediately loses.

2. **State Transition**:
   * From a state with `i` stones, the current player can choose any non-zero square number $k^2 \le i$ to remove, leaving the opponent with `i - k * k` stones.
   * If there exists **at least one** valid move $k$ such that `dp[i - k * k] == false` (meaning the move forces the opponent into a losing position), then the current player can guarantee a win from state `i` (`dp[i] = true`).
   * If all possible square removals lead to positions where `dp[i - k * k] == true` (winning positions for the opponent), the current player cannot win, so `dp[i] = false`.

3. **Optimization**:
   * For each state `i`, as soon as we find a single square move that leaves the opponent in a losing state (`!dp[i - k * k]`), we mark `dp[i] = true` and `break` early to move to the next state.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(n * sqrt(n))
 * Space Complexity: O(n) auxiliary space for the DP array
 */
public class Solution {

    public boolean winnerSquareGame(int n) {
        boolean[] dp = new boolean[n + 1];

        // Bottom-up Dynamic Programming
        for (int i = 1; i <= n; i++) {
            // Try all possible square numbers k * k <= i
            for (int k = 1; k * k <= i; k++) {
                // If removing k*k stones forces opponent into a losing state, current player wins
                if (!dp[i - k * k]) {
                    dp[i] = true;
                    break; // Found a winning move, no need to check further k
                }
            }
        }

        return dp[n];
    }
}
```
