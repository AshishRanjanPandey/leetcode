# 🚀 LeetCode 1477 — Find Two Non-overlapping Sub-arrays Each With Target Sum

### 📝 Problem Description
Given an array of integers `arr` and an integer `target`.

You have to find two non-overlapping sub-arrays of `arr` each with a sum equal to `target`. There can be multiple answers, so you have to find an answer where the sum of the lengths of the two sub-arrays is minimum.

Return the minimum sum of the lengths of the two required sub-arrays, or return `-1` if you cannot find such two sub-arrays.

---

### 💡 Intuition & Approach
1. **Sliding Window:** Since all elements in `arr` are positive ($arr[i] \ge 1$), we can use a two-pointer sliding window (`left`, `right`) to find contiguous sub-arrays that sum to `target`.
2. **Dynamic Programming Array (`minLen`):** Let `minLen[i]` record the shortest length of any valid sub-array ending at or before index `i`.
3. **Tracking the Global Minimum:**
   - When the sliding window sum equals `target`, the current sub-array length is `currLen = right - left + 1`.
   - If a valid non-overlapping sub-array exists strictly to the left of the current window (`left > 0` and `minLen[left - 1] != INF`), we check if `currLen + minLen[left - 1]` is smaller than our global minimum answer.
   - Update `minLen[right]` with the minimum of `minLen[right - 1]` and `currLen`.

---

### 💻 Java Solution

```java
import java.util.Arrays;

/**
 * Problem: Find Two Non-overlapping Sub-arrays Each With Target Sum (LeetCode 1477)
 * Language: Java 17
 */
class Solution {
    public int minSumOfLengths(int[] arr, int target) {
        int n = arr.length;
        
        // Step 1: Initialize DP array to store the minimum length of a valid sub-array up to index i
        int[] minLen = new int[n];
        Arrays.fill(minLen, Integer.MAX_VALUE);

        int left = 0;
        int currentSum = 0;
        int minTotalLength = Integer.MAX_VALUE;

        // Step 2: Traverse the array using a sliding window
        for (int right = 0; right < n; right++) {
            currentSum += arr[right];

            // Shrink the window from the left if the sum exceeds target
            while (currentSum > target && left <= right) {
                currentSum -= arr[left];
                left++;
            }

            // Carry forward the best length seen so far from the previous index
            if (right > 0) {
                minLen[right] = minLen[right - 1];
            }

            // If a valid sub-array with the target sum is found
            if (currentSum == target) {
                int currLen = right - left + 1;

                // Step 3: Check if there is a valid non-overlapping sub-array before 'left'
                if (left > 0 && minLen[left - 1] != Integer.MAX_VALUE) {
                    minTotalLength = Math.min(minTotalLength, currLen + minLen[left - 1]);
                }

                // Update minLen for the current right boundary
                minLen[right] = Math.min(minLen[right], currLen);
            }
        }

        // Step 4: Return result or -1 if two non-overlapping sub-arrays are not found
        return minTotalLength == Integer.MAX_VALUE ? -1 : minTotalLength;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :--- | :--- |
| **Time Complexity** | $O(N)$ | The two-pointer window traverses the array such that each element is visited at most twice (once by `right` and once by `left`), resulting in linear time. |
| **Space Complexity** | $O(N)$ | An auxiliary array `minLen` of size $N$ is required to store the minimum length of valid sub-arrays up to each prefix boundary. |
