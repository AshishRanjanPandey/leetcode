# 🚀 Distribute Elements Into Two Arrays I

### 📝 Problem Description

You are given a **1-indexed** array of distinct integers `nums` of length $n$.

You need to distribute all the elements of `nums` between two arrays `arr1` and `arr2` using $n$ operations:
- In the first operation, append `nums[1]` to `arr1`.
- In the second operation, append `nums[2]` to `arr2`.
- Afterwards, in the $i$-th operation:
  - If the last element of `arr1` is strictly greater than the last element of `arr2` (`arr1.back() > arr2.back()`), append `nums[i]` to `arr1`.
  - Otherwise, append `nums[i]` to `arr2`.

The array `result` is formed by concatenating `arr1` and `arr2` (`result = arr1 + arr2`).

Return the array `result`.

---

### 💡 Intuition & Strategy

1. **Direct Simulation**:
   - The constraints are small ($3 \le n \le 50$), and the problem directly provides the step-by-step rules.
   - We simulate the process using two dynamic lists/arrays `arr1` and `arr2`.

2. **Initialization**:
   - Place `nums[0]` into `arr1`.
   - Place `nums[1]` into `arr2`.

3. **Sequential Distribution**:
   - For every index $i$ from $2$ to $n - 1$:
     - Compare the last element inserted into `arr1` with the last element inserted into `arr2`.
     - If `arr1[last] > arr2[last]`, append `nums[i]` to `arr1`.
     - Otherwise, append `nums[i]` to `arr2`.

4. **Concatenation & Output**:
   - Merge `arr1` followed by `arr2` into a single output array of size $n$.

5. **Complexity**:
   - **Time Complexity**: **$O(n)$** — A single pass of length $n$ to distribute elements, followed by copying elements to the result array.
   - **Space Complexity**: **$O(n)$** — Auxiliary space used by the two dynamic lists to store the partitioned elements.

---

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.List;

/**
 * Language: Java 17
 * Time Complexity: O(n)
 * Space Complexity: O(n)
 */
public class Solution {

    public int[] resultArray(int[] nums) {
        int n = nums.length;
        List<Integer> arr1 = new ArrayList<>();
        List<Integer> arr2 = new ArrayList<>();

        // Step 1: Initial assignments
        arr1.add(nums[0]);
        arr2.add(nums[1]);

        // Step 2: Distribute remaining elements based on the last values
        for (int i = 2; i < n; i++) {
            int last1 = arr1.get(arr1.size() - 1);
            int last2 = arr2.get(arr2.size() - 1);

            if (last1 > last2) {
                arr1.add(nums[i]);
            } else {
                arr2.add(nums[i]);
            }
        }

        // Step 3: Concatenate arr1 and arr2 into result array
        int[] result = new int[n];
        int idx = 0;

        for (int val : arr1) {
            result[idx++] = val;
        }
        for (int val : arr2) {
            result[idx++] = val;
        }

        return result;
    }
}
```
### 📊 Complexity Analysis

| Type | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $O(n)$ | We perform a single loop over $n - 2$ elements, doing $O(1)$ operations per step, followed by an $O(n)$ pass to merge the lists into the final array. |
| **Space Complexity** | $O(n)$ | Requires auxiliary storage for `arr1` and `arr2`, which collectively hold all $n$ integers. |
