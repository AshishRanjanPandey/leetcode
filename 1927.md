# 🎮 LeetCode 1927: Sum Game

### 📝 Problem Description

Alice and Bob take turns playing a game, with Alice starting first.

You are given a string `num` of even length consisting of digits and `'?'` characters. On each turn, a player will do the following if there is still at least one `'?'` in `num`:
1. Choose an index `i` where `num[i] == '?'`.
2. Replace `num[i]` with any digit between `'0'` and `'9'`.

The game ends when there are no more `'?'` characters in `num`.

For **Bob** to win, the sum of the digits in the first half of `num` must be equal to the sum of the digits in the second half. For **Alice** to win, the sums must **not** be equal.

Assuming Alice and Bob play optimally, return `true` if Alice will win and `false` if Bob will win.

---

### 💡 Intuition & Strategy

1. **Game Invariants & Move Parity**:
   * Let `S1`, `S2` be the initial digit sums of the left and right halves.
   * Let `Q1`, `Q2` be the count of `'?'` in the left and right halves.
   * If the total number of question marks `(Q1 + Q2)` is **odd**, Alice gets the final move. She can always adjust the final digit to make the sums unequal, guaranteeing an **Alice win (`true`)**.

2. **Symmetric Pairing Strategy (Bob's Winning Condition)**:
   * When `(Q1 + Q2)` is **even**, Bob plays second and can pair his moves with Alice:
     * If Alice fills a `'?'` on one side with digit `d`, Bob can place `9 - d` in another `'?'` on the same side.
     * Each pair of `'?'` on the same side contributes exactly `9` to that half's sum.
     * Opposite-side question marks cancel out symmetrically.
   * The side with more question marks will effectively gain an expected sum contribution of:
     `Delta = 9 * (|Q1 - Q2| / 2)`
   * Bob can force an exact tie if and only if the initial sum difference precisely offsets this gain:
     `2 * (S1 - S2) == 9 * (Q2 - Q1)`

3. **Complexity**:
   * **Time Complexity**: `O(n)` — Single linear pass over the string `num` of length `n`.
   * **Space Complexity**: `O(1)` — Uses a few integer variables for counters and running sums.

---

### 💻 Java Solution

```java
/**
 * Problem: LeetCode 1927 - Sum Game
 * Language: Java 17
 * Time Complexity: O(n)
 * Space Complexity: O(1)
 */
class Solution {

    public boolean sumGame(String num) {
        int n = num.length();
        int sum1 = 0, sum2 = 0;
        int q1 = 0, q2 = 0;

        for (int i = 0; i < n; i++) {
            char c = num.charAt(i);
            if (i < n / 2) {
                if (c == '?') {
                    q1++;
                } else {
                    sum1 += c - '0';
                }
            } else {
                if (c == '?') {
                    q2++;
                } else {
                    sum2 += c - '0';
                }
            }
        }

        // If the total number of '?' is odd, Alice always wins.
        // Otherwise, Bob wins iff 2 * (sum1 - sum2) == 9 * (q2 - q1).
        return (q1 + q2) % 2 != 0 || 2 * (sum1 - sum2) != 9 * (q2 - q1);
    }
}
```
