# 🎯 LeetCode: Distinct Subsequences

### 📝 Problem Description

Given two strings `s` and `t`, return the number of distinct subsequences of `s` which equals `t`[cite: 1].

The test cases are generated so that the answer fits on a 32-bit signed integer[cite: 1].

**Example 1:**
- **Input:** `s = "rabbbit"`, `t = "rabbit"`[cite: 1]
- **Output:** `3`[cite: 1]
- **Explanation:**
  As shown below, there are 3 ways you can generate "rabbit" from `s`:
  1. `ra_b_bbit` $\rightarrow$ `rabbbit` (skip 2nd 'b')[cite: 1]
  2. `rab__bit`  $\rightarrow$ `rabbbit` (skip 3rd 'b')[cite: 1]
  3. `rabb__it`  $\rightarrow$ `rabbbit` (skip 1st 'b')[cite: 1]

**Example 2:**
- **Input:** `s = "babgbag"`, `t = "bag"`[cite: 1]
- **Output:** `5`[cite: 1]
- **Explanation:**
  As shown below, there are 5 ways you can generate "bag" from `s`:
  1. `ba____g`  $\rightarrow$ `babgbag`[cite: 1]
  2. `ba__g__`  $\rightarrow$ `babgbag`[cite: 1]
  3. `b___bag`  $\rightarrow$ `babgbag`[cite: 1]
  4. `__bgbag`  $\rightarrow$ `babgbag`[cite: 1]
  5. `____bag`  $\rightarrow$ `babgbag`[cite: 1]

**Constraints:**
- $1 \le s.\text{length}(), t.\text{length}() \le 1000$[cite: 1]
- `s` and `t` consist of English letters.[cite: 1]

---

### 💡 Intuition & Strategy

1. **Subproblem Definition**:
   Let $dp[j]$ denote the number of times the prefix of `t` of length $j$ ($t[0..j-1]$) appears as a subsequence in the current prefix of `s`[cite: 1].

2. **Base Case**:
   - An empty string `t` ($j = 0$) is formed in exactly $1$ way from any prefix of `s` (by selecting the empty subsequence)[cite: 1].
   - Therefore, initialize $dp[0] = 1$[cite: 1].

3. **Transitions & Decisions**:
   For each character `sChar = s.charAt(i)`:
   - If `sChar == t.charAt(j - 1)`:
     - We can either pair `sChar` with `t.charAt(j - 1)` (adding $dp[j - 1]$ ways) or skip `sChar` (retaining $dp[j]$ ways)[cite: 1].
     - Transition: $dp[j] = dp[j] + dp[j - 1]$[cite: 1]
   - If `sChar != t.charAt(j - 1)`:
     - We must skip `sChar`, so $dp[j]$ remains unchanged ($dp[j] = dp[j]$)[cite: 1].

4. **Space Optimization (2D to 1D)**:
   - Notice that calculating the new value of $dp[j]$ only depends on its old value and the old value of $dp[j - 1]$[cite: 1].
   - By iterating $j$ backwards from $n$ down to $1$, we safely compute the updates in-place using a single 1D array without overwriting needed states[cite: 1].

5. **Complexity**:
   - **Time Complexity**: $O(m \times n)$ — Two nested loops iterating over the lengths of `s` ($m$) and `t` ($n$)[cite: 1].
   - **Space Complexity**: $O(n)$ — Single 1D dynamic programming array of size $n + 1$[cite: 1].

### 💻 Java Solution

```java
/**
 * Problem: Distinct Subsequences
 * Language: Java 17
 * Time Complexity: O(m * n)
 * Space Complexity: O(n)
 */
class Solution {

    public int numDistinct(String s, String t) {
        int m = s.length();
        int n = t.length();

        // If s is shorter than t, it is impossible to form t
        if (m < n) {
            return 0;
        }

        // dp[j] stores the count of subsequences matching t[0..j-1]
        int[] dp = new int[n + 1];

        // Base case: an empty string t can always be formed in 1 way
        dp[0] = 1;

        // Step 1: Iterate through each character of s
        for (int i = 0; i < m; i++) {
            char sChar = s.charAt(i);

            // Step 2: Iterate backwards through t to update the 1D DP table in-place
            for (int j = n; j >= 1; j--) {
                if (sChar == t.charAt(j - 1)) {
                    dp[j] += dp[j - 1];
                }
            }
        }

        // Step 3: Return total distinct subsequences matching all of t
        return dp[n];
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Description |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(m \times n)$ | Outer loop runs $m$ times (length of `s`) and inner loop runs $n$ times (length of `t`), performing $\mathcal{O}(1)$ updates per state. |
| **Auxiliary Space** | $\mathcal{O}(n)$ | Optimized from $\mathcal{O}(m \times n)$ using a single 1D array `dp` of size $n + 1$. |
| **Best Case Time** | $\mathcal{O}(1)$ | Immediate exit when $m < n$ since `s` cannot contain `t` as a subsequence. |
