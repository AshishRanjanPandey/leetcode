# 🚀 Maximum Length Substring With Two Occurrences

### 📝 Problem Description

Given a string `s`, return the maximum length of a substring such that it contains **at most two occurrences** of each character.

---

### 💡 Intuition & Strategy

1. **Sliding Window (Two Pointers)**:
   * We want to find the longest contiguous window $[L, R]$ such that no character appears more than $2$ times.
   * As we expand the window by moving the right pointer $R$, we track character frequencies in an array of size $26$ (since $s$ contains only lowercase English letters).

2. **Window Contraction**:
   * If adding character `s[R]` causes its frequency to exceed $2$, the current window becomes invalid.
   * We incrementally advance the left pointer $L$ and decrement the frequency of `s[L]` until the count of `s[R]` drops back to $2$.

3. **Global Maximum Update**:
   * At each step after restoring the validity of the window, the candidate substring length is $R - L + 1$.
   * We maintain $\text{maxLength} = \max(\text{maxLength}, R - L + 1)$.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17 / 21
 * Time Complexity: O(N) — each character is visited at most twice (by left and right pointers)
 * Space Complexity: O(1) — fixed-size array of size 26 for ASCII lowercase English letters
 */
public class Solution {

    public int maximumLengthSubstring(String s) {
        int[] freq = new int[26];
        int maxLength = 0;
        int left = 0;

        for (int right = 0; right < s.length(); right++) {
            char currentChar = s.charAt(right);
            freq[currentChar - 'a']++;

            // Shrink the window from the left if any character frequency exceeds 2
            while (freq[currentChar - 'a'] > 2) {
                freq[s.charAt(left) - 'a']--;
                left++;
            }

            // Update the maximum length of a valid window
            maxLength = Math.max(maxLength, right - left + 1);
        }

        return maxLength;
    }
}
```
### 📊 Complexity Breakdown

| Complexity Aspect | Metric | Details |
| :--- | :--- | :--- |
| **Best Case Time** | $\mathcal{O}(N)$ | Occurs when no character frequency exceeds 2; `right` pointer traverses once and `left` never moves. |
| **Worst Case Time** | $\mathcal{O}(N)$ | Every element is processed at most twice (once added by `right`, once removed by `left`). Total pointer operations $\le 2N$. |
| **Average Case Time** | $\mathcal{O}(N)$ | Linear scan through the string with constant amortized window adjustments. |
| **Auxiliary Space** | $\mathcal{O}(1)$ | Fixed-size frequency array of length 26 (`int[26]`), independent of string length $N$. |
| **Call Stack Space** | $\mathcal{O}(1)$ | Iterative two-pointer approach with no recursive overhead. |
