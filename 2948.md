# 🎯 LeetCode 2948: Make Lexicographically Smallest Array by Swapping Elements

### 📝 Problem Description

You are given a **0-indexed** array of positive integers `nums` and a positive integer `limit`.

In one operation, you can choose any two indices `i` and `j` and swap `nums[i]` and `nums[j]` if:
$$|nums[i] - nums[j]| \le limit$$

Return the *lexicographically smallest array* that can be obtained by performing the operation any number of times.

---

### 💡 Intuition & Strategy

1. **Equivalence Classes & Transitivity**:
   * If element $A$ can be swapped with element $B$ ($|A - B| \le \text{limit}$) and $B$ can be swapped with $C$ ($|B - C| \le \text{limit}$), then $A, B,$ and $C$ belong to the same connected component.
   * Transitivity guarantees that any two elements in the same connected group can be swapped with each other through a chain of valid adjacent swaps.
   * Therefore, all numbers in a group can be rearranged arbitrarily across the set of indices occupied by that group.

2. **Greedy Grouping & Placement**:
   * Pair each number with its original index: `(nums[i], i)`.
   * Sort the pairs in ascending order by their values.
   * Iterate through the sorted pairs to segment them into disjoint groups:
     * A new group starts whenever $\text{value}[k] - \text{value}[k - 1] > \text{limit}$.
   * For each identified group:
     * Extract and sort the original index positions belonging to the group.
     * Place the smallest values of the group into the smallest original index positions.

3. **Complexity**:
   * **Time Complexity**: $O(n \log n)$ — Sorting the value-index pairs takes $O(n \log n)$. Sorting the disjoint index subsets across all groups also sums to at most $O(n \log n)$.
   * **Space Complexity**: $O(n)$ — To store the pairs, group indices, and the final output array.

---

### 💻 Java Solution

```java
/**
 * Problem: LeetCode 2948 - Make Lexicographically Smallest Array by Swapping Elements
 * Language: Java 17
 * Time Complexity: O(n log n)
 * Space Complexity: O(n)
 */
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.List;

class Solution {

    public int[] lexicographicallySmallestArray(int[] nums, int limit) {
        int n = nums.length;

        // 1. Pair each value with its original index
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums[i];
            pairs[i][1] = i;
        }

        // 2. Sort pairs ascending by value
        Arrays.sort(pairs, (a, b) -> Integer.compare(a[0], b[0]));

        int[] result = new int[n];
        int i = 0;

        // 3. Process connected components
        while (i < n) {
            int j = i + 1;
            // Expand group while adjacent values differ by <= limit
            while (j < n && pairs[j][0] - pairs[j - 1][0] <= limit) {
                j++;
            }

            // Collect and sort original indices occupied by this group
            List<Integer> indices = new ArrayList<>();
            for (int k = i; k < j; k++) {
                indices.add(pairs[k][1]);
            }
            Collections.sort(indices);

            // Assign smallest group values to the smallest original index positions
            for (int k = 0; k < indices.size(); k++) {
                result[indices.get(k)] = pairs[i + k][0];
            }

            i = j;
        }

        return result;
    }
}
```
### 📊 Complexity Breakdown

| Step / Operation | Time Complexity | Space Complexity | Description |
| :--- | :---: | :---: | :--- |
| **Pairing & Sorting Pairs** | $O(n \log n)$ | $O(n)$ | Pair each element with its index and sort all $n$ elements by value. |
| **Component Segmentation** | $O(n)$ | $O(1)$ | Single pass over sorted pairs to partition them into connected groups. |
| **Group Indices Sorting** | $O(n \log n)$ | $O(n)$ | Sorting original indices per group: $\sum O(k_i \log k_i) \le O(n \log n)$. |
| **Result Reconstruction** | $O(n)$ | $O(n)$ | Place sorted group values into sorted index positions in the result array. |
| **Overall** | **$O(n \log n)$** | **$O(n)$** | Dominated by the initial sorting of pairs and auxiliary storage. |
