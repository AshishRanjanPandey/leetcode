# 🚀 Stone Game II

### 📝 Problem Description

Alice and Bob continue their games with piles of stones. There are a number of piles arranged in a row, and each pile has a positive integer number of stones `piles[i]`. The objective of the game is to end with the most stones.

Alice and Bob take turns, with Alice starting first.

On each player's turn, that player can take all the stones in the first $X$ remaining piles, where $1 \le X \le 2M$. Then, we set $M = \max(M, X)$. Initially, $M = 1$.

The game continues until all the stones have been taken.

Assuming Alice and Bob play optimally, return the maximum number of stones Alice can get.

---

### 💡 Intuition & Strategy

1. **Suffix Sum Precomputation**:
   * Precalculate the total number of stones remaining from index `i` to the end: `suffixSum[i] = sum(piles[i...n-1])`.
   * At any turn starting at index `i`, the total stones available to both players combined is `suffixSum[i]`.

2. **Minimax Dynamic Programming with Memoization**:
   * Define `dp(i, M)` as the **maximum stones** the current player can collect starting from pile `i` with multiplier parameter `M`.
   * **Base Case**: If $i + 2M \ge n$, the current player can take all remaining piles in a single move. Hence, `dp(i, M) = suffixSum[i]`.
   * **State Transition**: The current player can choose to take $X$ piles where $1 \le X \le 2M$. 
     * Taking $X$ piles leaves the opponent in state `(i + X, max(M, X))`.
     * The opponent will play optimally to get `dp(i + X, max(M, X))` stones.
     * Therefore, the current player's score for choosing $X$ is:
       $$\text{currentScore} = \text{suffixSum}[i] - \text{dp}(i + X, \max(M, X))$$
     * The player greedily maximizes `currentScore` over all valid choices of $X$.

3. **Memoization**:
   * Store state results in `memo[i][M]` to avoid re-evaluating subproblems.

---

### 💻 Java Solution

```java
/**
 * Language: Java 17
 * Time Complexity: O(n^3) where n = piles.length
 * Space Complexity: O(n^2) auxiliary space for memoization table and recursion stack
 */
public class Solution {

    private int[][] memo;
    private int[] suffixSum;
    private int n;

    public int stoneGameII(int[] piles) {
        n = piles.length;
        memo = new int[n][n + 1];
        suffixSum = new int[n + 1];

        // Precompute suffix sums from right to left
        for (int i = n - 1; i >= 0; i--) {
            suffixSum[i] = suffixSum[i + 1] + piles[i];
        }

        return dp(0, 1);
    }

    private int dp(int i, int M) {
        // Base case: If we can take all remaining piles in one move, take them all
        if (i + 2 * M >= n) {
            return suffixSum[i];
        }

        // Return cached result if already computed
        if (memo[i][M] != 0) {
            return memo[i][M];
        }

        int maxStones = 0;

        // Try taking X piles where 1 <= X <= 2M
        for (int X = 1; X <= 2 * M; X++) {
            // Opponent score from the next state
            int opponentScore = dp(i + X, Math.max(M, X));
            
            // Current player's score is total remaining minus opponent's best score
            int currentScore = suffixSum[i] - opponentScore;
            
            maxStones = Math.max(maxStones, currentScore);
        }

        memo[i][M] = maxStones;
        return maxStones;
    }
}
```
### 📊 Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(n^3)$ | There are $\mathcal{O}(n^2)$ unique DP states defined by index $i$ ($0 \le i < n$) and multiplier $M$ ($1 \le M \le n$). For each state, we iterate $X$ from $1$ up to $2M$ ($\le n$) choices. |
| **Space Complexity** | $\mathcal{O}(n^2)$ | Required for the `memo` matrix of size $n \times (n + 1)$ to cache intermediate subproblem results, along with $\mathcal{O}(n)$ recursive call stack depth. |
| **Auxiliary Space** | $\mathcal{O}(n)$ | Used by the `suffixSum` array of size $n + 1$ to calculate range sums in $\mathcal{O}(1)$ time. |
