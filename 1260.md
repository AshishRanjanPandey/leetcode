# 🚀 LeetCode 1260 — Shift 2D Grid

### 📝 Problem Description
Given a 2D grid of size `m x n` and an integer `k`, return the 2D grid after applying the shift operation `k` times.

In one shift operation:
* Element at `grid[i][j]` moves to `grid[i][j + 1]`.
* Element at `grid[i][n - 1]` moves to `grid[i + 1][0]`.
* Element at `grid[m - 1][n - 1]` moves to `grid[0][0]`.

---

### 💻 Java Solution

```java
import java.util.ArrayList;
import java.util.List;

/**
 * Problem: Shift 2D Grid (LeetCode 1260)
 * Language: Java 17
 */
class Solution {
    public List<List<Integer>> shiftGrid(int[][] grid, int k) {
        int m = grid.length;
        int n = grid[0].length;
        int total = m * n;
        
        // Step 1: Normalize k to eliminate redundant full grid cycles
        k = k % total;
        
        List<List<Integer>> result = new ArrayList<>();
        
        // Step 2: Directly build the shifted grid by mapping back to source coordinates
        for (int i = 0; i < m; i++) {
            List<Integer> row = new ArrayList<>();
            for (int j = 0; j < n; j++) {
                // Convert 2D position (i, j) to a flattened 1D index
                int current1D = i * n + j;
                
                // Calculate where this target cell gets its value from in 1D space
                // Adding 'total' prevents negative indices during modulo operations
                int prev1D = (current1D - k + total) % total;
                
                // Map the 1D source index back to 2D row and column indices
                int prevRow = prev1D / n;
                int prevCol = prev1D % n;
                
                row.add(grid[prevRow][prevCol]);
            }
            result.add(row);
        }
        
        return result;
    }
}
```
### ⏱️ Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Time Complexity** | $\mathcal{O}(m \times n)$ | We visit each cell in the $m \times n$ grid exactly once to calculate its target value. |
| **Space Complexity** | $\mathcal{O}(m \times n)$ | Auxiliary space required to construct and store the resulting 2D list of size $m \times n$. |
